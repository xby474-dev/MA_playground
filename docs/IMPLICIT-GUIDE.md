# 隐函数实验 · 保持约束，读出变化

MA Playground v1.8，第九个实验。离线入口：`dist/implicit-lab.html`，包含全部九个实验。无外部字体、CDN、服务器或账号依赖。

## 一个问题，四次升级

**如果自由变量先改变，依赖变量要怎样补偿，才能继续满足 F=0？**

每一站都保留三个彼此不同的对象：工作点、只改变自由变量后的点、一阶预测点；能够显式计算时再加入精确分支点。橙色表示输入变化／约束误差，蓝色表示线性修正，绿色表示精确分支。相同颜色跨站含义相同。精确分支是当前预设的解析参考，不是一个通用求根器的输出。

### 01 补回误差

默认圆 `F=x²+y²−1`。拖动圆上的工作点，或用 θ 滑块选择位置。拖动橙点改变自由变量。点击三个阶段按钮，或播放整段过程：

1. **只动自由变量**：把 x 改为 x+h，y 不动。当前读数显示真实 F，而不只是线性近似。
2. **一阶修正**：沿依赖方向补上 `k=Dg·h`。切线上的预测点通常尚未回到曲线。
3. **精确分支对照**：显示高阶修正，把预测点连到当前解析分支。

下方约束空间展示的是 `A h` 与 `B k` 的线性抵消，与上方真实 `F` 残差分开。点击“步长减半”，再展开误差图：要观察的是隐函数的归一化余项，而不是仅仅两个点靠近。

### 02 选对依赖变量

点击“看临界点”把圆的工作点设为 (1,0)。`F_y=0`，但曲线本身没有坏。交换为“自由 y → 依赖 x”，导数公式、变量名称、切线预测同步交换；这一方向 `F_x≠0`。

接着切换三个不同边界例子：

- `(y−x)³=0`：整个零集就是 y=x，唯一光滑隐函数仍存在。逆偏导公式无定义，但由显式解得 **Dg=1**。页面不会把两者混为一谈。
- `y³−x=0`：y=∛x 唯一且连续，原点不可微；交换依赖变量可得到光滑的 x=y³。
- `y²−x²=0`：零集有两支。页面选出的 y=x 只是参考分支，不是对整个零集的唯一性结论。

另有正常抛物线对照。在奇异处，不能执行的修正阶段会禁用。没有实数分支的目标点显示“未定义”，不是补一个 0。

### 03 曲面上的修正

选择二次曲面 `z=x²+xy+y²` 或球面上半球。右侧自由变量平面可以拖动基点和位移；主图可拖动旋转。点击“只动 x／只动 y”理解导数的两列，再恢复任意方向。

此时 `g:ℝ²→ℝ`，**Dg 是 1×2 行矩阵**，同时接受 dx、dy，输出高度修正 dz。曲面、切平面、梯度方向、真实 F 与修正后的残差同步更新。球面基点保留在所选图像的内部；目标点可以离开有效范围，此时不伪造精确分支。自由变量平面与三维投影是同一组数据，不是两个独立动画。

### 04 解一台线性机器

自由变量 x∈ℝ²、依赖变量 y∈ℝ²、约束 F∈ℝ²。上方的两张平面分别展示自由变量的位置／位移和依赖变量的变化；下方单独展示约束空间。

拖动自由变量，观察橙色 `A dx`；蓝色 `B dy` 如何抵消它？矩阵 `Dg=−B⁻¹A` 直接把自由变化转成依赖修正。界面明确标记矩阵维度、各个空间、坐标尺度；不要把不同自动尺度下的箭头像素长度当作数值长度。

逐步选择 λ=1、0.1、0.02：仍然可逆，但同样的小约束变化可能需要更大的依赖修正。选择 **λ=0**：矩阵像坍缩成一条线。“不同向误差”展示无解，“同向误差”展示可解却不唯一。没有用伪逆制造一个貌似唯一的隐函数。

## 证明和独立判断

每站的“为什么成立”有四步推导，可逐步或全部展开；证明与实验互跳时保留参数。证明首先说明局部存在与唯一性，再使用链式法则求 Dg；不会把形式微分当成存在性证明。完整证明与计算规格见 `IMPLICIT-MATHEMATICS.md`。

“自己判断”有八道带理由的选择题，区分 g、Dg、DF，定理前提，有限步与微分，局部性，以及矩阵乘法顺序。答题草稿仅保存在内存，重置会清除；不发送到外部服务。

## 操作与访问

- 图上可拖手柄，主要手柄可用方向键；所有参数都有对应滑块或按钮。
- 动画可暂停、继续；减少动态效果偏好会使用离散阶段切换。
- “分享实验”保存 URL 参数，离线分享还必须发送同一 HTML 文件。
- CSV 导出当前参数下缩小步长的数值误差，不导出一个伪造的证明。
- 手机端控件前置、图形分栏变纵向；桌面固定的概念名称不改变。

页面只使用已核对的预设例子。浮点读数不是严格区间计算，有限采样不证明极限或存在性；退化零点由预设解析条件明确判断。
