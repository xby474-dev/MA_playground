# 级数判别：条件、量词、版本与反例

本实验是**给定通项族的解析案例库**，不是从有限数值自动判定任意无穷级数的算法。数值只负责展示，所有状态来自下面列出的公式和证明。测试核对实现，不构成机器形式化证明。

## 1. 先约定要证明什么

始终令 $b_n=|a_n|$，从 $n=1$ 开始。令 $S_N=\sum_{n=1}^N a_n$、$A_N=\sum_{n=1}^N b_n$。

- **严格正项**：每项为正；稀疏例子则是含零的非负项。
- **绝对收敛**：$\sum b_n<\infty$。
- **条件收敛**：$S_N$ 有有限极限，同时 $A_N\to+\infty$。
- **交错赋号**：$a_n=(-1)^{n-1}b_n$ 是一种形式，不是一种收敛结论。允许零的形式表示不保证非零项严格交替。

正项（或非负项）级数的收敛与绝对收敛一致，不存在“条件收敛”的分类。比较、极限比较、积分判别在这里作用于 $\sum b_n$。若它们证明 $\sum b_n$ 发散，只排除绝对收敛，不自动证明带符号的 $\sum a_n$ 发散。比值或根值的 $>1$ 分支则直接否定通项趋零，可以判原级数发散。

所有最终条件允许去掉有限前缀。参考级数必须**先独立知道敛散**。把未知的原级数选作自己的参照不能产生新证据。

## 2. 图中每个节点的精确定义

绿色图只画下列**收敛充分条件**之间的蕴含，不把“某方法可用于判发散”混进同一个条件节点。

| 节点 | 条件 |
|---|---|
| 比值 | 从某项起 $b_n>0$，普通极限 $L=\lim b_{n+1}/b_n$ 存在，且 $L<1$ |
| 根值 | $\rho=\limsup b_n^{1/n}<1$，允许零项 |
| 标准极限比较 | 固定 $v_n>0$，$b_n/v_n\to c\in(0,\infty)$，且已知 $\sum v_n<\infty$ |
| 直接比较 | 同一已选参照，存在 $C>0,N_0$ 使 $0\le b_n\le Cv_n$ 对所有 $n\ge N_0$ 成立，且 $\sum v_n<\infty$ |
| 标准积分条件 | $b_n=f(n)$，$f$ 正、连续、最终不增，且 $\int f<\infty$ |
| Leibniz | 交错赋号，$b_n\ge0$ 最终不增且 $b_n\to0$ |
| 绝对收敛 | $\sum b_n<\infty$ |
| 原级数收敛 | $S_N\to S\in\mathbb R$ |
| 通项趋零 | $a_n\to0$；只有必要性 |

使用上极限的根值判别，能够处理普通根值极限不存在的例子。上极限不由当前有限窗口的最大值计算。本实验的“标准极限比较”明确指双向版；$c=0$ 或 $c=\infty$ 的单向扩展另外展示，不错误宣布整个方法失效。

## 3. 八条绿色箭头的证明

### 3.1 比值条件 → 根值条件

选择 $L<r<1$，则存在 $N$，对一切 $n\ge N$，$b_{n+1}\le rb_n$。递推得到

$$b_n\le b_Nr^{n-N}=Cr^n.$$

取 $n$ 次根，$C^{1/n}\to1$，于是 $\limsup b_n^{1/n}\le r<1$。这证明图中所需的蕴含。普通比值极限存在时，普通根值极限等于它也是标准结论，但本箭头无需更强结论。

### 3.2 根值条件 → 绝对收敛

取 $\rho<r<1$。由上极限定义，存在 $N$ 使对所有 $n\ge N$，$b_n^{1/n}\le r$，从而 $b_n\le r^n$。几何尾部有限，比较判别给出 $\sum b_n<\infty$。

如果 $\rho>1$，选择 $1<r<\rho$，有无穷多个 $n$ 满足 $b_n^{1/n}>r$，因此 $b_n$ 不趋零。若 $\rho=1$，无结论。比值极限 $L>1$ 也会使项最终增长；但是**仅比值上极限大于 1 不能判发散**，见齿状例子。

### 3.3 标准极限比较 → 直接比较（固定参照）

用误差 $c/2$，存在 $N$ 使

$$\frac c2\le\frac{b_n}{v_n}\le\frac{3c}2 \quad(n\ge N).$$

于是得到双侧比较。参照收敛使用上界，参照发散使用下界，证明同敛散。

若商趋零且参照收敛，则最终 $b_n\le v_n$，仍能证明收敛。若商趋无穷且参照发散，则最终 $b_n\ge v_n$，仍能证明 $\sum b_n$ 发散。相反两种方向不够。商在常数区间内振荡时，直接比较可用，但不能称为“商极限的单向扩展”。

### 3.4 直接比较 → 绝对收敛

对任意 $m\ge n\ge N_0$，

$$0\le\sum_{k=n}^m b_k\le C\sum_{k=n}^m v_k.$$

右侧任意充分晚的尾块都可小于给定 $\varepsilon$；由 Cauchy 准则和实数完备性，$\sum b_n$ 收敛。去掉或增加有限前缀不影响结论。

如果把参照量词改为“存在任意一个收敛 $v$”，绝对收敛时平凡地可以选 $v=b$。因此图中不宣称直接比较与绝对收敛之间有无条件的严格强弱，也不宣称“总能找到参照”是一种有效求解算法。

### 3.5 积分条件 → 绝对收敛

最终单调不增保证

$$f(n+1)\le\int_n^{n+1}f(x)\,dx\le f(n).$$

从某个整数 $N$ 求和，得到

$$\int_N^{M+1}f\le\sum_{n=N}^M b_n\le f(N)+\int_N^Mf.$$

广义积分有限当且仅当非负项部分和有界；单调有界定理给出同敛散。这一论证不是“把任意画出来的曲线积分”。在整数处安排任意窄的高峰可以使采样值与积分脱节，单调条件不可偷偷删除。

### 3.6 Leibniz → 原级数收敛

先去掉有限前缀，使交错尾部从正项开始且幅度不增。偶数部分和递增，奇数部分和递减，而且

$$S_{2m}\le S_{2m+1},\qquad S_{2m+1}-S_{2m}=b_{2m+1}\to0.$$

两者有界且差趋零，故收敛到同一个极限 $S$。整个部分和列收敛，并有 $|S-S_N|\le b_{N+1}$。实验中满足此法的例子从第 1 项就单调，因此直接显示 $N$ 处的标准夹逼区间。区间端点是公式的浮点估值，不是严格区间算术。

### 3.7 绝对收敛 → 原级数收敛

$$\left|\sum_{k=n}^m a_k\right|\le\sum_{k=n}^m|a_k|.$$

右侧通过绝对收敛满足 Cauchy 尾块条件，故左侧也满足。实数完备性保证部分和有有限极限。此处可以回到实验 04 查看使用了什么完备性。

### 3.8 原级数收敛 → 通项趋零

$a_n=S_n-S_{n-1}\to S-S=0$。逆否命题合法：通项不趋零则原级数发散。逆命题不成立：调和级数每个二进区块至少积累 $1/2$，虽通项趋零但总和发散。

## 4. 八个函数族的独立解析结论

参数范围为 $p\in[1/4,3]$，$q\in[0.35,1.2]$。其限制是为了控制教学与数值范围，不是定理的适用范围。

1. **几何项** $b_n=q^n$：$q<1$ 时绝对收敛，$q\ge1$ 时通项不趋零，无论是否交错赋号都发散。普通比值和根值都为 $q$。
2. **p 项** $b_n=n^{-p}$：比值和根值极限都为 1。积分给出绝对收敛当且仅当 $p>1$。交错赋号后，$0<p\le1$ 时条件收敛，$p>1$ 时绝对收敛。
3. **望远镜项** $b_n=1/[n(n+1)]$：$b_n\le1/n^2$，总和为 1；$S_N=1-1/(N+1)$。相对 $1/n^2$ 的商趋于 1，并在 $[1/2,1]$ 内。任何赋号都绝对收敛。
4. **齿状几何** $b_n=c_nq^n$，奇数 $c_n=1$，偶数 $c_n=4$：根值趋于 $q$，比值在 $4q$ 与 $q/4$ 之间交替。$q<1$ 时被 $4q^n$ 控制而绝对收敛。可选范围内 $4q>1$，每个奇项后都上升，不能满足最终单调的积分或 Leibniz 条件。$q\ge1$ 时通项不趋零。
5. **摆动 p 项** $b_n=c_n/n^p$，奇数 $c_n=1$，偶数 $c_n=3$：$n^{-p}\le b_n\le3n^{-p}$，绝对收敛当且仅当 $p>1$。比值两列趋于 $3,1/3$，根值趋于 1。相对同一个 $n^{-p}$ 的商一直为 $1,3$，不能使用标准双向极限比较。若交错赋号且 $p\le1$，

   $$a_{2k-1}+a_{2k}=(2k)^{-p}\left[(2k/(2k-1))^p-3\right]\le -(2k)^{-p}$$

   对充分大 $k$ 成立，偶数部分和趋于 $-\infty$，所以原级数发散；交错符号本身并未拯救它。
6. **对数项** $b_n=1/[(n+1)\ln^p(n+1)]$：延拓 $f(x)=1/[(x+1)\ln^p(x+1)]$ 对 $x\ge1$ 正、连续且严格递减。其导数分子含 $-(\ln(x+1)+p)$，所以为负。换元 $u=\ln(x+1)$ 得到积分 $\int_{\ln2}^{\infty}u^{-p}du$，故绝对收敛当且仅当 $p>1$。比值和根值均趋 1。相对 $1/n$ 的商总趋零，但这个发散参照无法判敛散。交错且 $p\le1$ 时条件收敛。
7. **稀疏项** $b_n=1/n^2$ 当 $n=2^k,k\ge0$，其余为 0：$0\le b_n\le1/n^2$，总和 $\sum_{k\ge0}4^{-k}=4/3$。比值有无穷多个未定义位置，普通根值极限不存在，但根值上极限为 1。参照 $2^{-n}$ 时，商在非零尖峰处趋于无穷，却在无穷多个零项处等于零，所以**没有趋于无穷的普通商极限**。交错赋号形式下，非零项也不严格交替；页面单独标明。
8. **不单调抵消** $b_{2k-1}=1/k$，$b_{2k}=1/k+1/k^2$：正号总和发散，相对 $1/n$ 的商趋于 2，全局夹在 $[1,4]$。交错赋号后

   $$S_{2m}=-\sum_{k=1}^m1/k^2,\qquad S_{2m+1}-S_{2m}=1/(m+1)\to0.$$

   所以原级数收敛；绝对值每对至少为 $2/k$，故条件收敛。每个偶项幅度都更大，标准 Leibniz 条件失败。必须控制奇数部分和：仅有“分组后收敛”不够。比值与根值极限均为 1。

## 5. 反推与不可比的范围

- 根值条件不推出普通比值条件：齿状几何 $q=1/2$。
- 绝对收敛不推出根值小于 1：$1/n^2$。
- 固定参照下的上界不推出商极限存在：摆动 p 项 $p=2$，参照固定为 $1/n^2$。
- 原级数收敛不推出绝对收敛：交错调和。
- 通项趋零不推出收敛：调和级数。
- 即使在交错序列内，收敛也不推出最终幅度单调：不单调抵消例。
- **根值条件 vs 标准积分收敛条件**：齿状几何是前者不推出后者的反例；$1/n^2$ 是后者不推出前者的反例；几何 $2^{-n}$ 满足两者。
- **Leibniz 条件 vs 绝对收敛**：交错调和是前者不推出后者的反例；交错齿状几何是后者不推出前者的反例；交错几何满足两者。

不画箭头不等于证明不可比。不可比要两方向的反例；有交集也不意味着两条件等价。实验只比较明确的条件，不给全部判别法一个总排名。

## 6. 数值与实现边界

- `series-math.js` 独立于绘图。`seTruth`、`seEvaluate` 的结论不读取 N、动画进度或采样数组。
- 计算 $\log b_n$，再计算比值和根值，避免很小的项相除；零分母直接返回未定义。下标必须是正整数。
- 部分和使用补偿加法；仍是浮点显示，不是任意精度证明。
- 商图以 $\log_{10}(b_n/v_n)$ 显示。零项使用单独的 ×，不补造一个极小正数。
- 不同图的纵轴含义明确分开。最近 12 项柱状图会按窗口缩放，不能拿像素比较不同窗口的绝对大小。
- 图上的有限 $n$ 次根、比值、部分和都不能给出最终极限或上极限。解析状态由预设通项的严格计算给出。
- 比较法只针对已列出的参照以及证明出的常数/极限界。没有合适证据时明确返回无法判断，不偷偷借用已知最终分类。
