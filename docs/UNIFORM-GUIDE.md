# 同一个 N 挑战：使用指南

入口：侧栏“07 函数项级数”，或 dist/uniform-lab.html。单文件包含七个实验，直接双击即可离线使用。

## 一条连续路线

1. **条件地图**：从默认 x^N 开始。绿色箭头表示带条件的一般命题；节点颜色表示当前例子。实线8条、反推/删条件问题8条；点击节点或箭头开始研究。不是所有节点都能排成单一强弱链。
2. **同一个 N 挑战**：先锁定x=.6，增加N；再切到“追踪x_N”。前者让每个点单独等，后者允许对方在你报N以后另选一个坏点。移动点不是固定点，不拿它反驳逐点收敛。
3. **为什么能交换**：每条关系4步证明，可逐步阅读或展开全篇；例子、域、N、ε保留。总共16条路线、64步。充分条件不满足并不自动判结论失败。
4. **自己判断**：8道带理由的问题，作答可在往返导航时保留，修改答案会清除旧反馈。刷新不承诺持久保存问答。

## 先只改区间

默认[0,1]：x^N逐点但不一致，极限跳跃；误差上确界1不取到。去掉1：极限变连续，但上确界仍为1。缩到[0,r]：E_N=r^N，一致且正规。放大视图**不**是缩小讨论域。

切换几何级数：在[0,r]找到M证书；在[0,1)每个点都能求和，但每一阶整体误差无界；加入端点1则连全域有限和都不存在。请比较“+∞”和“未定义”。

## 再交换高度、面积、斜率

同一工作台有四种视角。高度页画S_N、S、误差带，另画误差切片和解析上确界。面积页用独立积分公式；尖峰宽度变窄但面积一直1。斜率页比较S_N′和S′；小波纹高度一致趋零，但内点1/2的斜率不停交替。M预算页把“对每个点”改成“对每一项先付全域预算”，交错线性项证明一致不必正规。

不要从图上曲线碰巧接近就交换极限。先看前提，再看对应的解析证明。

## 控件与操作

- 函数族、集合E、右端点r共同决定数学问题；N/ε/x决定观察。
- 播放逐项增加N，可暂停、±1、拖动N；动画上限512，数学论证不受此限。
- 探针可拖动；键盘左右移动、Home/End到边界。开放端点从不作为选中的合法点。
- “找一个统一N”使用解析尾界；有证书时跳到证书N；没有时转为坏点追踪；超出动画上限保留说明。
- 下方两个证书分别对固定点和整个E，均控制全部后续项。
- 分享链接包含函数、集合、参数、视角、路线、证明步骤；离线文件分享也需要接收者有相同文件或网页入口。
- CSV包含有限样本及尖峰折点等解析特征点，未定义值不会伪造为0。
- 桌面是分支有向图，手机重新排成完整的分支卡，不暗示“连续→积分”或反向定理。
- 减少动态效果偏好使播放变成较慢离散步；离开模块或页面隐藏时暂停。

## 推荐自测顺序

先解释逐点与一致的量词，再说x^N的sup为什么不取到。然后自行预测缩域、尖峰、波纹的结果。最后用“交错线性项”检查正规与一致的反推，用“常数漂移”补全逐项求导的前提。
