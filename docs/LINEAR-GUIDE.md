# 导数，是局部线性机器。· 实验指南

## 先打开

离线直接双击 `dist/linear-lab.html`。它包含全部八个实验；侧栏可切回另外七个。开发时运行 `npm run dev`，打开终端打印的网址，在侧栏选择第八个实验。部署版路由为 `#lab=linear`。

不需要账号、API key、CDN 或后端。分享按钮复制的是当前页面与参数；离线文件需要接收者同时拥有 HTML，单独发本地文件路径并不能让别人访问你的电脑。

## 一条线走到底

**缩小位移 → 读懂两列 → 连接机器 → 投影找中值 → 自己判断。**

初始函数 F(u,v)=(u²−v,u³+v) 可贯穿全部四站。切换站点不会丢失工作点和位移；“为什么成立”里也保留同一状态。图旁有滑块，图上有可直接拖动的手柄；手机端把参数放在图前面，避免过小的双栏。

### 1. 缩小位移

拖橙色端点改变 h，拖绿色点改变工作点 p。右图画的不是函数值位置，而是相对于 F(p) 的输出位移。绿实线是真实增量，橙虚线是 Jacobian 预测，蓝线是二者差距。默认把输出除以 ρ=||h|| 放大，避免“两个箭头都缩到看不见”被误认为理解了可微性。

点击“ρ 减半”或“自动缩小位移”。下方同时显示原始余项、归一化误差和全方向解析界。仿射正例没有余项；“把 h 设为 0”明确显示比值未定义。切换预设不需要输入公式。

### 2. 读懂两列

直接点矩阵第 1/2 列，h 会转到相应的坐标方向，保持当前长度。页面把“这一列”“这一列乘以 ρ”“真实单位差商”区分开。再拖回一个斜方向，就能看到两列怎样加权组合。

可展开“换一组输入坐标”：旋转基，但保持同一个物理 h。看到矩阵和坐标数字改变而输出不变之后，再读坐标表示的证明。换基后要重新点选某一列，才能沿新基方向走。

### 3. 连接机器

三图依次是 h、Ah、B(Ah)，其中 A=JF(p)，B=JG(F(p))。三图使用相同坐标比例；绿色网格是同一个输入小方块的线性像。点播放，蓝色光点按三段依次传递。光点是进度指示，不是新的数学曲线。

“合并两步”把表达式合成 (BA)h。数字同时列出逐步预测和合成预测，以及真实复合函数的变化。选择另一台 G、改变 p 或 h，都同步重算。勾选“错误顺序 ABh”可以观察顺序的重要性；本版矩阵均为方阵，反着乘虽可计算却未必正确，一般维数甚至不允许反乘。

### 4. 投影找中值

拖 p/y 改输入线段；拖右侧罗盘中的 a 改输出投影方向。λ 手柄/滑块指定在线段上走到哪里。上方是输入线段和输出曲线，下方是真正的一元实值函数 φ(λ)。点绿色候选 ξ 或“找中值点”，让投影函数的切线与割线平行。

再点“没有共同中值点”的反例。先按 a=e₁，再按 a=e₂，观察候选点不重合，并阅读下方的精确矛盾证明。旋转其他方向，看“先定方向，后找点”。更换二次或仿射预设，观察有共同点的正常案例。

## 证明、理解检查、导出

四站各有四步证明与完整展开。八道理解检查把答案与理由一起反馈。答题草稿仅在当前页面内存中保留，刷新即丢失，重置会清除；没有上传。

CSV 导出固定当前方向上 33 个尺度的数据、真实/预测增量、余项及已证明的上界，并附投影方程系数和候选。CSV 是解析公式的浮点计算，不是精确有理数算术。

## 键盘与边界

Tab 聚焦图上的 p、h、y、a。方向键移动，Shift+方向键加快，Home 复位。中值候选可用 Enter/Space 激活。所有操作也有按钮、滑块或选择框。减少动态效果偏好使动画变为较慢的离散更新；离开当前实验会销毁播放与拖动监听。

当前所有三种 F 定义在 R²；本版没有任意映射编辑器。p、y 范围为 [−1.5,1.5]²，h 最长 1.2，非零尺度通常从 1.2 到 10⁻⁴；单独的零位移按钮用于检查定义边界。绘图是有限的、读数是浮点的，证明见 `LINEAR-MATHEMATICS.md`。

## 开发入口

- `src/linear-math.js`：纯数学和稳定增量/余项。
- `src/linear-state.js`：白名单参数、范围、序列化。
- `src/linear-content.js`：学习路线、证明和理解检查。
- `src/linear-plots.js`：无第三方依赖的 SVG。
- `src/linear-lab.js`：监听、手柄、动画及清理。
- `styles/linear.css`：与主站一致的局部样式。
- `tests/linear.test.mjs` / `tests/linear_browser_test.py`：实际回归测试。

一般浏览器验收可运行 `npm run build` 后执行 `python tests/linear_browser_test.py`。受限环境可显式加 `--offline-harness --browser /usr/bin/chromium`，这会执行完整离线构建，但不验证 HTTP 模块加载链路；两种模式不混称。
