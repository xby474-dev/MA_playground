# 偏导、连续、可微与偏导连续：统一实验的数学核对

本文是 v1.2 实验的离线数学说明。所有函数在原点判断，默认定义在原点的某个开邻域。图形和有限数值用于探索；本文件的恒等式、估计与证明才是结论依据。

## 1. 与用户提供的教材图的对应

用户上传的图以“偏导数存在、连续、可微”为主节点，给出可微推出偏导存在、可微推出连续，以及带附加条件的箭头。本版保留它的逻辑组织，并按本次要求将“偏导连续”单列成第四个节点。

原图上方“在某邻域上偏导数有界”不可省略。实验将这条条件写完整：**所有偏导在原点的某个开邻域内存在且有界**。它不是“原点两个偏导是有限数”。

## 2. 四个节点究竟表示什么

令 O=(0,0)，h=(x,y)，ρ=√(x²+y²)。

- **P：偏导存在。** fₓ(O)、fᵧ(O) 两个通常的双侧差商极限均存在。
- **C：连续。** ∀ε>0，∃δ>0，使 ‖h‖<δ 时 |f(h)−f(O)|<ε。
- **D：可微。** ∃线性映射 L，∀ε>0，∃δ>0，使 0<‖h‖<δ 时 |f(h)−f(O)−L(h)|/‖h‖<ε。
- **C∂：偏导在原点连续。** 存在原点的开邻域 U，两个偏导在 U 内都存在，并在 O 连续。这里只要求偏导在 O 连续，不额外要求 U 内每个点都连续；所以不直接把该节点标为“在 U 上属于 C¹”。

图上的箭头是全称逻辑命题；节点的“成立/不成立”是当前特定函数的性质。换一个函数不会改变定理。

## 3. 三条基本定理与一条附条件定理

### C∂ ⇒ D

在包含 O 的足够小开矩形中写

f(x,y)−f(0,0) = [f(x,y)−f(0,y)] + [f(0,y)−f(0,0)]。

偏导在邻域内存在，所以两条坐标线段上的一元限制函数可用中值定理：

f(x,y)−f(0,0) = fₓ(ξ,y)x + fᵧ(0,η)y，

其中 ξ 在 0 与 x 之间，η 在 0 与 y 之间。零长度线段直接贡献 0，无需定义对应中间点。

取 L(x,y)=fₓ(O)x+fᵧ(O)y。给定 ε>0，由两个偏导在 O 连续，可以选同一个 δ，使距离 O 小于 δ 时，每个偏导与其原点值之差均小于 ε/√2。中间点的距离不大于 ρ，于是

|R(x,y)| ≤ (ε/√2)(|x|+|y|) ≤ ερ。

同一个 δ 对所有方向有效，故 D 成立。证明没有先假设 f 的二元连续性。

### D ⇒ P

写 f(h)−f(O)=Ax+By+R(h)，|R(h)|/ρ→0。取 h=(t,0)，则

[f(t,0)−f(O)]/t = A+R(t,0)/t → A。

绝对值 |R(t,0)/t|=|R(t,0)|/|t|→0，所以正负侧都成立。沿 y 轴同理得到 B。由此可见，若导数存在，它只能是 L=fₓ(O)x+fᵧ(O)y；不能为不同方向分别选择不同的 L。

### D ⇒ C

有限维线性映射满足 |L(h)|≤‖L‖ρ。在充分小邻域，|R(h)|≤ρ。因此

|f(h)−f(O)|≤(‖L‖+1)ρ→0。

给定 ε，再令 δ≤ε/(‖L‖+1) 即得连续性的定义。

### 邻域内偏导存在且有界 ⇒ C

假设在某开矩形 U 内偏导处处存在，且 |fₓ|≤Mₓ、|fᵧ|≤Mᵧ。沿同样两段坐标线应用中值定理，得到

|f(x,y)−f(O)| ≤ Mₓ|x|+Mᵧ|y| ≤ √(Mₓ²+Mᵧ²)ρ。

更一般地，在较小矩形内，任意两点也有该 Lipschitz 估计。这个结论不是 D：除以 ρ 后，右边只是常数，并未趋于 0。

## 4. 光滑正例不是装饰

四个正例都在全平面光滑，P、C、D、C∂ 全部成立。不同梯度和余项强调的几何内容不同。

| f | 原点梯度 | 线性映射 L | 所有方向的归一化误差 |
|---|---|---|---|
| x²+y² | (0,0) | 0 | 精确上确界 ρ |
| xy | (0,0) | 0 | 精确上确界 ρ/2 |
| sin x cos y | (1,0) | x | 统一上界 2ρ²/3，不称精确上确界 |
| x²+xy+y² | (0,0) | 0 | 精确上确界 3ρ/2 |

前两项可直接用 x=ρcosθ、y=ρsinθ 计算。第四项为 ρ(1+sin2θ/2)，取最大值即 3ρ/2。

第三项采用

sin x cos y − x = (sin x−x)cos y + x(cos y−1)。

|sin x−x|≤|x|³/6，|cos y−1|≤y²/2，故余项绝对值≤|x|³/6+|x|y²/2≤2ρ³/3。计算实现对小 x 使用 sin x−x 的级数，对 cos y−1 使用 −2sin²(y/2)，避免近原点消去误差。

一个正例不能证明一条对所有函数成立的箭头；一般性来自上一节。

## 5. 三个指定反例

### A. xy/(x²+y²)，原点补 0

沿坐标轴恒为 0，所以原点两个偏导均为 0。非原点处分母非零，可由通常法则求偏导，因此整个邻域内的偏导确实存在。

沿 (t,t)，t≠0，函数值为 1/2，不趋于 f(O)=0。因此 P ⇏ C，也不可微。

严格的 ε–δ 反证：取 ε₀=1/4。任意 δ>0，都可选择 0<√2|t|<δ，此时 |f(t,t)−f(O)|=1/2>ε₀。

非原点

fₓ = y(y²−x²)/(x²+y²)²，fᵧ = x(x²−y²)/(x²+y²)²。

沿 (0,t)，fₓ=1/t，在任意原点邻域无界，故不违反有界偏导定理。

原点候选 L=0；在半径 ρ 上，|f|/ρ=|sin2θ|/(2ρ)，精确上确界是 1/(2ρ)。它只是一个失败的候选线性近似，绝不标为“切平面”。

### B. |x|+|y|

|f|≤√2ρ，所以 C 成立。

沿 x 轴的差商为 |t|/t：正侧 +1，负侧 −1。x 偏导不存在，y 偏导同理不存在。于是 P、D、C∂ 不成立，反驳 C⇒P。

这里没有由原点偏导生成的 L；实现返回 null，不用 0 伪装“缺失导数”。图形可以显示 |f|、|f|/ρ，但明确称为“高度/相对高度”，不称微分余项。对应精确相对高度上确界为 √2。

### C. x²sin(1/x)，x=0 时对所有 y 补 0

在 x=0 这条直线上，x 偏导的差商为 t sin(1/t)→0，y 偏导为 0。原点 L=0。

|R|/ρ ≤ x²/ρ ≤ ρ→0，故 D、C、P 成立。

x≠0 时 fₓ=2x sin(1/x)−cos(1/x)，fᵧ=0；x=0 时两偏导为 0。令

xₙ=1/(2πn)，x′ₙ=1/((2n+1)π)，n=1,2,…，

则两列 (xₙ,0)、(x′ₙ,0) 都趋于 O，且偏导精确分别为 −1、+1，不趋于原点值 0。这是对 D⇒C∂ 的严格反例。

在 |x|<1 内仍有 |fₓ|≤3，故偏导局部有界。**存在、有界、连续是三件不同的事。**

## 6. 旧实验的桥梁反例保持完整

g=xy/√(x²+y²)，g(O)=0。

|g|≤ρ/2，所以 C 成立；坐标轴上的两个偏导为 0，所以 P 成立。但

|g−L|/ρ=|sin2θ|/2，

沿 45° 恒为 1/2，不能可微。它证明 P∧C ⇏ D，同时分别是 P⇏D、C⇏D 的反例。

非原点 gₓ=y³/ρ³、gᵧ=x³/ρ³，各自绝对值≤1；原点两偏导为 0。因此邻域内偏导存在且有界，仍不能保证 D。沿 (0,t)，gₓ=sign(t)，所以 C∂ 也不成立。

## 7. 三个迁移判断题

A. h=x³/(x²+y²)，h(O)=0：|h|≤ρ，P、C 成立；原点梯度 (1,0)。唯一候选 L=x，余项为 −xy²/(x²+y²)，沿 45° 的误差比例恒为 1/(2√2)，所以 D 不成立。非原点 hₓ=x²(x²+3y²)/(x²+y²)²，沿 (0,t) 为 0，不趋于原点偏导 1，所以 C∂ 不成立。精确方向上确界是 max |cosθ|sin²θ=2/(3√3)。

B. h=x²y²/(x²+y²)，h(O)=0：|h|≤ρ²/4，原点偏导均为 0，故 |R|/ρ≤ρ/4→0。非原点 hₓ=2xy⁴/ρ⁴，hᵧ=2yx⁴/ρ⁴，各自绝对值≤2ρ→0，所以 C∂ 成立，四项均真。分式并不自动意味着病态。

C. h=ρ²sin(1/ρ)，h(O)=0：|h|/ρ≤ρ，原点偏导为 0，故 P、C、D 成立。非原点 hₓ=2x sin(1/ρ)−(x/ρ)cos(1/ρ)。沿正 x 轴的上述两列点仍有偏导 −1、+1，所以 C∂ 不成立。

每题除四项判断外，还必须选择支持判断的理由。正确性质与正确理由分开评分，不把猜对选项当成理解。

## 8. 数值、图像、证明各自的职责

1. 属性真值表是经过本文件推导的作者数据，不是运行时用采样“检测”连续或可微。
2. 图表只画 ρ∈[10⁻⁴,1] 的有限尺度。曲线趋势不是量词证明。
3. 标为“上界”的数据不伪装成精确上确界；负例使用具体路径或序列否定全称命题。
4. 振荡图用经过解析验证的两列点，显示恒等式 ±1；测试另用实际偏导表达式求值进行交叉检查。不以有限网格绘得平滑为由宣告偏导连续。
5. 比值函数的网格与截面不跨过原点连接；原点补定义用实点标注。网格留孔是显示策略，不是从定义域删掉原点。
6. 曲面水平与垂直显示比例独立，屏幕上的视觉角度不能用作真实导数。
7. 精确坐标轴方向会将浮点余弦的微小舍入余数归零，避免将“x=0”错误显示为一个极小非零 x，从而触发高频振荡。
8. 测试验证公式实现、状态、UI 和部署资源，不声称机器证明了任意函数的定理。
