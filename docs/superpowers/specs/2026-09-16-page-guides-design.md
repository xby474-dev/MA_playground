# MA Playground 页面内导览设计

日期：2026-09-16

## 目标

让第一次直接打开任意实验页面的学习者，不依赖 `docs` 目录，也能立刻理解本页研究的问题、建议操作顺序、观察重点和最终结论。导览是实验入口，不替代现有的定义、证明和完整操作指南。

## 交互方案

- 三类实验页面都在页面标题和主实验内容之间显示统一的“本页导览”卡片。
- 每个实验首次进入时默认展开；不使用弹窗，不阻断探索。
- 用户开始实验后仍可手动收起，避免自动折叠造成上下文丢失。
- 收起后显示“重新打开本页导览”按钮。
- 导览提供“开始第 1 步”入口，并链接到相应的完整 `docs` 指南。
- 状态按实验和页面阶段保存到当前浏览器的 `sessionStorage`，刷新后保留本次学习状态；清除浏览数据后重新展开。

## 统一内容结构

1. 本页要回答的问题
2. 建议操作顺序
3. 重点观察
4. 本页结论
5. 常见误区

内容使用短句、编号步骤和可扫读的小标题；数学证明仍通过“定义与证明”页面及完整指南提供。

## 三个实验的内容

### 极限实验

核心问题是：只沿几条路径趋近原点，能否说明多元极限存在？操作顺序为选择路径、切换路径族、缩小趋近尺度、比较函数值与收敛曲线、进入证明。重点是路径结果、原点值与极限的区别，以及有限路径不能替代全体路径。结论是多元极限要求所有允许路径趋向同一个值。

### 关系实验

核心问题是：偏导存在、连续、可微和偏导连续之间哪些方向可以推出，哪些不能反推？操作顺序为选择函数、预测性质、点击定理箭头、切换反例并检查失败原因。重点是区分节点的当前函数状态和箭头的一般命题，并结合曲面、截面和归一化误差判断。结论是偏导存在不自动推出连续或可微，定理方向和反例方向必须分开理解。

### Green–Gauss–Stokes 场实验

核心问题是：三大公式为什么能把区域内部的局部变化与边界积分联系起来？操作顺序为选择定理、观察简单向量场和区域、调整方向/分块/曲面、对照内部局部贡献与边界账本、进入证明。重点是公共边界的反向抵消、方向改变引起的符号变化，以及旋度/散度与环流/通量的配对。结论是局部累积经过内部抵消，最终只留下外边界的整体效应。

## 工程边界

- 尽量复用各实验已有的文案和样式变量，不复制完整 `docs` 内容。
- 导览不改变 URL 状态、实验计算、分享参数、答题结果和导出数据。
- 导览自身必须有可访问名称、键盘可操作的收起/展开按钮，并适配手机布局。
- 三个实验共用一个内容/交互模式；页面-specific 文案由实验入口传入。

## 验证标准

- 三个实验首次进入时均能看到展开的导览。
- 收起、重新打开和刷新后的状态符合约定。
- “开始第 1 步”和完整指南链接可用。
- 导览不遮挡或破坏现有实验控件、图形、证明和自测。
- 现有 Node 测试、构建和浏览器回归全部通过，并新增导览结构与状态测试。
