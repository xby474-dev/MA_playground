# v1.6 一致收敛实验与页面导览设计

## 目标

将 v1.6 的第七个实验“每个点，还是所有点”合并到正式 MA Playground，并让它与 v1.5 的六个实验保持一致的学习入口。每个实验阶段顶部都提供默认展开的「本页导览」卡片：核心问题、三步开始、重点观察、本页结论、常见误区，以及指向 `docs` 完整指南的链接。

## 范围

- 合并一致收敛实验的数学模型、状态、图形、内容、控制器和样式。
- 扩展路由、侧栏导航、构建脚本和离线单文件入口，版本更新为 v1.6。
- 保留 v1.5 已有六个实验及其导览、分享、导出和测试行为。
- 为一致收敛实验的 `map`、`workshop`、`proof`、`challenge` 四个页面提供阶段化导览。
- 更新中英文 README、使用指南、数学推导、验证记录和交付状态。

## 交互设计

一致收敛实验包含四个阶段：条件地图、同一个 N 挑战、为什么能交换、自己判断。导览卡片在每个阶段显示对应的学习问题和目标控件；“开始第 1 步”只负责定位第一个相关控件，不改变数学结论。用户开始操作后可以收起导览，也可以重新打开。

导览中的观察对象明确区分：固定点与追踪点、误差带与解析上确界、部分和与极限、面积交换、导数斜率和量词顺序。有限网格、动画和单个案例不被描述为定理证明。

## 技术边界

页面导览继续复用 `src/page-guide.js` 的内容解析、sessionStorage 状态和事件委托。新增实验只添加 `uniform` 内容映射与目标选择，不复制一套独立的导览逻辑。v1.6 的统一收敛业务代码保持 `uniform-*` 模块边界，正式仓库中的 v1.5 测试修复和历史交付材料不被覆盖。

## 验收标准

- 七个导航入口、七个离线入口和 `#lab=uniform` 路由均可用。
- v1.5 六个实验的页面导览和既有交互不回退。
- v1.6 四个页面均默认显示导览，折叠/展开/定位/完整指南链接有效。
- Node 测试、生产构建、重复构建和 Chromium 浏览器套件通过。
- GitHub Actions 通过后部署 GitHub Pages；本地只保留正式 `MA-Playground` 目录。
