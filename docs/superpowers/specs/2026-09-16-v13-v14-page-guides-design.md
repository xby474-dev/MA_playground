# v1.3 / v1.4 页面导览设计

## 目标

让第一次进入 v1.3 完备性实验和 v1.4 Taylor 实验的学习者，在开始操作前立即知道本页要回答的问题、操作顺序、观察重点、结论和常见误区。

## 方案

复用现有 `page-guide.js` 共享组件与 `app.js` 的导览状态管理，不为每个实验复制一套交互。导览内容按实验和页面 screen 提供上下文：完备性覆盖 map、explore、proof、challenge；Taylor 覆盖 grow、error、boundary、proof、challenge。每页默认展开，用户可收起并在当前会话中按实验/页面恢复状态。

每张卡片包含五个固定区域和一个完整指南链接；“开始第 1 步”跳转到该页面的第一个有效控件。现有 v1.0–v1.2 导览、键盘操作、移动布局和无障碍语义保持不变。

## 验收

Node 内容测试验证九个页面均含完整导览字段、正确文档链接和独立状态键；浏览器回归验证首次展开、收起/重新打开、开始按钮定位及 v1.3/v1.4 页面切换不破坏实验状态。生产构建和 GitHub Actions 全部通过后推送 `main`，清理本地 v1.4 副本。
