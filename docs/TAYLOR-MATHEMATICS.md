# Taylor：一点信息，逐阶构造（v1.4）

本模块的核心不是拟合采样点，而是用 a 处已知的解析导数，构造次数不超过 n 的唯一局部多项式。图像、浮点读数、解析恒等式、有限阶余项定理及无穷级数收敛严格分层。

## 1. 条件与唯一性

设 f 在 a 有前 n 阶导数（对于余项另加下述充分条件）。在以 h=x−a 为基底的多项式 P=Σ c_k h^k 中，P^(j)(a)=j!c_j，因为 k<j 的项消失，而 k>j 的项在 h=0 为零。依次要求 P^(j)(a)=f^(j)(a) 唯一确定 c_j=f^(j)(a)/j!。因此

T_n(x)=Σ_{k=0}^n f^(k)(a)(x−a)^k/k!。

“n 阶 Taylor 多项式”是次数**不超过** n：例如 sin 在 a=0 的 T_1=T_2=x。

每个新增项的低阶导数在 a 全为零，故不破坏已匹配的信息。0 阶匹配函数值，1 阶匹配斜率，2 阶匹配二阶导数；几何曲率 κ=|f″|/(1+f′²)^(3/2) 并非 f″ 本身，但同时匹配 f′、f″ 后也匹配曲率。

动画进度 p=m+λ（0<λ<1）明确表示 Q=T_m+λ c_{m+1}h^(m+1)。它一般不是 T_{m+1}，也不直接继承该阶的余项界。若新增系数为零，过渡曲线不变，且这一阶导数本来就相同。URL 保存小数进度，暂停与分享都不伪造完成阶数。

## 3. 有限阶余项：固定 n，让 x→a

采用明确且足够的条件 f∈C^(n+1)(I)，其中开区间 I 包含 a 和 x。由微积分基本定理开始，反复分部积分得到

R_n(x)=f(x)−T_n(x)=1/n! ∫_a^x f^(n+1)(t)(x−t)^n dt。

n=0 就是基本定理。由分部积分，右式等于 R_{n−1}(x)−f^(n)(a)(x−a)^n/n!，给出归纳步骤；积分定向同时处理 x<a。

若在整个连接区间上 |f^(n+1)(t)|≤M，则

|R_n(x)|≤M|x−a|^(n+1)/(n+1)!。

积分中值定理还给出某个位于 a 与 x 之间的 ξ，使 R_n=f^(n+1)(ξ)(x−a)^(n+1)/(n+1)!。ξ 不必是 a。固定阶数，在 a 的小闭邻域内连续导数有界，因此 R_n=o(|x−a|^n)。本模块用这一充分光滑条件，不声称这是最弱的 Peano 形式假设。

### 代码中的 M

- exp：M=exp(max(a,x))。
- sin/cos：M=1。
- log：M=n!/[1+min(a,x)]^(n+1)，要求连接区间在 x>−1 内。
- reciprocal：M=(n+1)!/d^(n+2)，d=min(|1−a|,|1−x|)，且连接区间不能包含 1。
- flat：直接使用本例的精确余项 g(x)，不冒称它是通用的 Lagrange M。

候选整段半径 δ 从二进制数 2^(−j) 中选取。使用两端解析 M 的较大者控制 |h|≤δ 的整段导数，并检查充分公式小于 ε 的 99%，留出数值比较裕度。半径不是最大值，也不是收敛半径。公式本身提供数学充分条件；代码仅浮点计算公式，**没有宣称经过区间算术或形式化验证**。不得以有限采样最大误差冒充整段上界。

## 4. 固定 x，让 n→∞：另一种问题

T_n(x)→f(x) 当且仅当 R_n(x)→0。对于 exp、sin、cos，上述连接区间的 M 与 n 无关，且 |h|^(n+1)/(n+1)!→0。因而对每个固定实数 x，级数收敛到函数。这里没有宣称在整个无界 ℝ 上一致逼近，更不保证固定阶误差逐阶严格下降。

### 精确几何余项

令 u=(x−a)/(1−a)。有限恒等式 (1−u)Σ_{k=0}^n u^k=1−u^(n+1) 给出

R_n(x)=u^(n+1)/(1−x)，x≠1。

有限恒等式在收敛半径外也成立。|u|<1 时余项趋零；|u|≥1 时几何级数项不趋零，故不收敛。u=−1 时 T_n 来回振荡；u=1 时原函数本身无定义。半径 R=|1−a|。

### 对数的端点

a>−1，u=(x−a)/(1+a)，ln(1+x)=ln(1+a)+ln(1+u)。对有限几何恒等式积分，可得

ln(1+u)−Σ_{k=1}^n (−1)^(k−1)u^k/k = (−1)^n ∫_0^u t^n/(1+t) dt。

当 |u|<1，余项绝对值≤|u|^(n+1)/((n+1)(1−|u|))→0。在 u=1，上式的绝对值≤1/(n+1)→0，因而右端点收敛到 ln2。u=−1，原函数无定义，级数为负调和级数。|u|>1 时项不趋零。故相等区间为 −1<x≤1+2a，半径 1+a，右端点包含。

### 升阶反而变差

f=exp x，a=0，x=−2。T_0=1，T_1=−1。因为 0<e^(−2)<1，|e^(−2)−T_0|=1−e^(−2)<1+e^(−2)=|e^(−2)−T_1|。这是解析反例，不是采样推断。新增项为零（如 sin 的二阶）则误差不变。

## 5. 无限可微，不等于解析

g(0)=0，x≠0 时 g=exp(−1/x²)。对任意 m≥0，设 t=1/x²，选择整数 p>m/2，利用 e^t≥t^p/p! 得 |x|^(−m)g(x)≤p!t^(m/2−p)→0。

在非零处每阶导数为 P_k(1/x)g(x)，P_k 多项式，求导仍属同形。归纳：各阶导数在 0 连续且为 0；由差商再除以 x 的极限证明下一阶导数存在。因此 g∈C^∞ 且所有 Taylor 多项式恒为0。

固定 n：R_n(x)/|x|^n→0（有效的局部近似）。固定 x≠0：R_n(x)=g(x)>0，不随 n 变化。零级数收敛半径为 ∞，处处收敛到0，但只有在原点才等于 g。页面分别呈现级数收敛性与是否等于原函数。

## 6. 数值与绘图的诚实边界

Horner 法计算多项式；系数来自解析导数。几何例子的余项使用精确代数恒等式计算以避免灾难性相消，其浮点估值仍不是任意精度有理运算。一般函数的余项采用 f−T 浮点差，落入 32 ε_machine max(1,|f|,Σ|c_k h^k|) 的解释性舍入尺度时标为“接近浮点分辨率”，不判为恒等。

flat 在极小 x 的下溢同样标注。误差图在 10^(−14) 处截底，不表示值为0；y 轴按 f 决定而不随阶数跳动，图的纵向裁切不表示数学有界。原函数跨越奇点断开；多项式本身照常有定义。无定义误差为 null，不写0；图像不跨 pole 连线。
