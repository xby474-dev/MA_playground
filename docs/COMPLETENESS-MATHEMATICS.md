# 实数完备性的五种等价表述：条件、证明与精确构造

本模块的动画和有限数据不是数学证明。以下为本项目独立编排的证明和算术说明；引用资料用于核对定义、等价范围与标准论证，不是逐字转录。

## 0. 共同框架

在经典数学的**阿基米德有序域 K**内讨论。它有全序及与序相容的域运算，并且对每个 x∈K 存在自然数 n>x。由此对每个 ε>0，存在 N，使 n≥N 时 2⁻ⁿ<ε。ℚ 与 ℝ 都满足这个前提；它们的区别是完备性。

不能把本图推广为“所有有序域中，单独的 Cauchy 完备性都等价于上确界原理”。非阿基米德域不在此图的范围。阿基米德性不由这里的 Cauchy 假设偷偷导出。

图采用长度趋零的闭区间套：非空、闭、有界、嵌套，并满足 bₙ−aₙ→0，结论为域内**唯一**交点。在 ℝ 中，不要求长度趋零也保证交集非空，但不保证唯一。这里的 [a,b]ₖ 是 {x∈K:a≤x≤b}；ℚ 下是相对 ℚ 的闭区间。

五条单向证明组成强连通环：

上确界 → 单调有界 → 闭区间套 → BW → Cauchy 完备 → 上确界。

所以任意一个节点可以沿环推出任意另一个节点。不是把每条反向蕴含当成不证自明，更不是用目标定理反过来证明前提。ℚ 中五个普遍命题都不成立，但作为条件蕴含的箭头仍有效。

## 1. 命题的精确陈述

### 上确界原理 (LUB)

K 的每个非空、有上界的子集 A，都有属于 K 的上确界。

> s = sup A ∈ K

s 是上界：∀x∈A，x≤s；s 最小：∀ε>0，存在 x∈A 使 s−ε<x。上确界不必属于 A，但必须属于数系 K。

### 单调有界定理 (MCT)

K 中每个单调递增且有上界的数列，都收敛到 K 中的一个数。递减且有下界的情形同理。

> a₀ ≤ a₁ ≤ ⋯ ≤ M  ⇒  aₙ → ℓ ∈ K

这里的递增允许相等。有界仅是不会越过某道界线，不是已经证明有终点。极限必须仍在 K 内。

### 闭区间套定理 (NIP)

若非空闭有界区间 Iₙ=[aₙ,bₙ]ₖ 满足 Iₙ₊₁⊆Iₙ 且 bₙ−aₙ→0，则它们的交集在 K 中恰有一个点。

> ⋂ₙ₌₀^∞ [aₙ,bₙ]ₖ = {ℓ},  ℓ ∈ K

[a,b]ₖ 表示 {x∈K:a≤x≤b}。本图采用“长度趋零、交点唯一”的版本。在 ℝ 中，不要求长度趋零也能保证非空，但未必唯一。

### Bolzano–Weierstrass 定理 (BW)

K 中每个有界数列，都有一个收敛到 K 中某点的子列。

> n₁ < n₂ < ⋯ ,   xₙₖ → ℓ ∈ K

子列只能删项，不能重排；要求保留严格递增的原始下标。不要求原数列收敛。“无限多个项”指无限多个下标，数值可以重复。

### Cauchy 完备性 (CC)

K 中每个 Cauchy 数列，都收敛到 K 中的一个数。

> ∀ε>0 ∃N ∀m,n≥N : |xₘ−xₙ|<ε

Cauchy 条件不预设终点。m 与 n 独立，允许相隔任意远；只看相邻差趋于零远远不够。收敛 ⇒ Cauchy 不需要完备性；反向才需要。

## 2. 环上五条证明

### sup-mono: 把数列的值域，交给上确界。

**允许使用：** 只假设上确界原理；使用单调性与极限的定义。

给定任意单调递增、有上界的数列 (xₙ)。不是先假定它有极限，而是先为这个值域找一个最小上界。

**1. 制造集合**

令 A={xₙ:n≥0}。它非空，且由题设有上界。上确界原理给出 s=sup A∈K。

> A≠∅，A 有上界 ⇒ s=sup A∈K

**2. 用“最小”挤出一项**

给定任意 ε>0，s−ε 不可能仍是 A 的上界；否则 s 不是最小上界。因此有某个 N 使 x_N>s−ε。

> s−ε < x_N ≤ s

**3. 单调性管住整个尾部**

对每个 n≥N，单调性给出 x_N≤xₙ，而 s 是上界给出 xₙ≤s。故 |xₙ−s|<ε。

> ∀n≥N：s−ε < x_N ≤ xₙ ≤ s

**4. 结论与反向入口**

ε 任意，因此 xₙ→s。非增且有下界的数列对 −xₙ 使用同一论证。要反向推出上确界，可沿图继续走完其余四条箭头。

> xₙ → sup{x₀,x₁,…} ∈ K

**不能混淆：** 图上的若干 aₙ 只是正例。这里证明的是任意单调有界数列；没有用动画“看起来变平”代替量词。

### mono-nested: 追踪左端点，把极限留在每一层。

**允许使用：** 只假设单调有界定理；使用保序的极限法则及长度趋零条件。

给定任意符合条件的 Iₙ=[aₙ,bₙ]ₖ。先确保一个点存在，再单独证明它唯一。

**1. 左端点单调而有界**

嵌套给出 aₙ≤aₙ₊₁≤bₙ₊₁≤bₙ。特别地，(aₙ) 单调递增，且每项都不超过 b₀。

> a₀ ≤ a₁ ≤ ⋯ ≤ b₀

**2. 从数列拿到一个域内点**

单调有界定理给出 aₙ→ℓ∈K。固定任意 j，对 n≥j 有 aⱼ≤aₙ≤bⱼ。取极限后 aⱼ≤ℓ≤bⱼ。

> ∀j：ℓ ∈ [aⱼ,bⱼ]ₖ

**3. 长度趋零负责唯一性**

若 ℓ、r 都属于全部区间，则对每个 n 都有 |ℓ−r|≤bₙ−aₙ。若两点不同，取 ε=|ℓ−r|/2 就与长度趋零矛盾。

> 0 ≤ |ℓ−r| ≤ bₙ−aₙ → 0

**4. 分清两个条件的作用**

所以交集恰为 {ℓ}。在此证明中，闭性使极限不跑出区间；长度趋零用于唯一性。恒定区间 [0,1] 的交集非空，却不是单点。

> ⋂ₙ Iₙ = {ℓ}

**不能混淆：** 对每个有限 n，Iₙ 非空，不能单靠这一句话交换量词，推出存在同一个点属于全部 Iₙ。

### nested-bw: 每次保留无限多项，而非屏幕上的多数。

**允许使用：** 只假设长度趋零的闭区间套定理；阿基米德性保证二分长度趋零。

给定任意有界数列 (xⱼ)。下面不是在有限散点里猜哪里密集，而是对无限下标集合做存在性论证。

**1. 把整列放进第一个盒子**

有界性让我们选择闭有界区间 I₀=[a,b]，a<b，包含所有项。将它分成两个闭半区间。至少有一个含无限多个项的下标。

> 无限集合 = 两个有限集合的并？不可能。

**2. 无限次二分，保留嵌套**

在选中的半区间中继续二分，每次选一个含无限多个下标的半区间 Iₖ。于是 Iₖ₊₁⊆Iₖ，长度为 (b−a)2⁻ᵏ→0。

> |Iₖ| = (b−a)/2ᵏ → 0

**3. 先有公共点，再选更晚的项**

闭区间套定理给出唯一 ℓ∈⋂Iₖ。递归选 nₖ>nₖ₋₁ 且 xₙₖ∈Iₖ；因为 Iₖ 含无限多个下标，任何有限下标之后仍有可选项。

> n₁<n₂<⋯，xₙₖ∈Iₖ，ℓ∈Iₖ

**4. 区间长度就是误差界**

两点同属 Iₖ，所以 |xₙₖ−ℓ|≤|Iₖ|→0。于是得到域内收敛子列。数值相同也可能有无限多个下标，例如常数列。

> |xₙₖ−ℓ| ≤ (b−a)2⁻ᵏ → 0

**不能混淆：** 有限点图不能判定“含无限多个项”。本实验的偶数子列由公式明确指定，不声称实现任意无限序列的自动抽取算法。

### bw-cauchy: 一条子列到达后，整个尾部都跟上。

**允许使用：** 只假设 Bolzano–Weierstrass；其余来自 Cauchy 定义与三角不等式。

给定任意 Cauchy 数列 (xₙ)。先证明有界，才能调用 BW；不能一开始就把未知终点写进定义。

**1. Cauchy 先保证有界**

在 Cauchy 条件里取 ε=1，得到 N。对 n≥N，有 |xₙ|≤|x_N|+1。前 N 项有限，与这个尾部界一起给出全列的一个界。

> |xₙ| ≤ max{|x₀|,…,|x_N|}+1

**2. BW 提供一个终点**

由 BW，存在严格递增下标 nₖ，使 xₙₖ→ℓ∈K。到这里，我们只知道子列收敛，还不能省去下一步。

> xₙₖ → ℓ ∈ K

**3. 用 ε/2 连起两段距离**

给定 ε>0。先选 N 使所有 m,n≥N 时 |xₘ−xₙ|<ε/2，再选 k 使 nₖ≥N 且 |xₙₖ−ℓ|<ε/2。

> |xₙ−ℓ| ≤ |xₙ−xₙₖ| + |xₙₖ−ℓ| < ε

**4. 固定的那一项，管住所有晚项**

上式对每个 n≥N 都成立，所以 xₙ→ℓ。若删去 Cauchy 条件，(−1)ⁿ 就是“子列收敛、全列不收敛”的反例。

> ∀ε>0 ∃N ∀n≥N：|xₙ−ℓ|<ε

**不能混淆：** “有一条收敛子列”不等于“全列收敛”。实验中 zⱼ=(−1)ʲaⱼ 不是 Cauchy；这一箭头须应用于 Cauchy 的 aₙ，而不是 zⱼ。

### cauchy-sup: 不先借用上确界，二分构造它。

**允许使用：** 只假设 Cauchy 完备性；阿基米德性保证二分长度趋零。

给定任意非空有上界的 A⊆K。整个过程中不能先写 s=sup A；那个 s 正是我们需要证明存在的对象。

**1. 一个不是上界，一个是上界**

取 x₀∈A，令 a₀=x₀−1，则 a₀ 不是上界；取任一上界 b₀。二分中点 m：若 m 是上界，保留 [aₙ,m]；否则保留 [m,bₙ]。

> aₙ 不是上界；bₙ 是上界

**2. 只靠宽度，证明 Cauchy**

不变量在二分中保持，且 bₙ−aₙ=(b₀−a₀)2⁻ⁿ。所有 m,n≥N 的 aₘ,aₙ 都落在 [a_N,b_N]，所以二者距离至多为该宽度。

> |aₘ−aₙ| ≤ (b₀−a₀)2⁻ᴺ → 0

**3. 完备性给点，再验证它是上界**

Cauchy 完备性给 aₙ→s∈K，宽度趋零又给 bₙ→s。每个 x∈A 都满足 x≤bₙ，取极限得 x≤s。因此 s 是上界。

> ∀x∈A：x≤bₙ ⇒ x≤s

**4. 验证最小性，闭合证明环**

若 c<s，由 aₙ→s 可取 n 使 aₙ>c。因 aₙ 不是上界，存在 x∈A 使 x>aₙ>c；所以 c 不是上界。故 s=sup A。

> c<s ⇒ ∃x∈A：c<aₙ<x ⇒ s=sup A

**不能混淆：** 一般集合中“m 是否为上界”是含全称量词的逻辑判定，不一定有计算算法。演示的二次不等式是可精确判定的特例。有理终点刚好命中时，上界构造把等号归入上界侧；展示区间为统一保留宽度把等号归入左侧，二者不可混称。

## 3. 贯穿五个视角的同一个构造

预设 d∈{2,3,9/4}。a₀=1,b₀=2。每次取有理中点 m=(aₙ+bₙ)/2；若 m²≤d，设 aₙ₊₁=m,bₙ₊₁=bₙ；否则设 aₙ₊₁=aₙ,bₙ₊₁=m。此处等号归入左端，方便保留每一层的正宽度。

对所有 n 均有：

- 1≤aₙ≤aₙ₊₁<bₙ₊₁≤bₙ≤2；
- bₙ−aₙ=2⁻ⁿ；
- aₙ²≤d<bₙ²；
- 0≤d−aₙ²<(bₙ−aₙ)(bₙ+aₙ)≤4·2⁻ⁿ。

这些不变量由一次二分直接归纳。设 aₙ=p/2ⁿ，则下一步用整数比较 d_den(2p+1)² 与 d_num·2²⁽ⁿ⁺¹⁾，无须计算平方根。代码使用 BigInt。绘图才将已得到的有理数转换为 Number；Math.sqrt 仅用于可隐藏的实数背景参照点。

### 在 ℝ 中识别终点，而不是先用终点定义构造

由任何已建立的完备性版本得到 aₙ 的域内极限 α。残差界及乘法的极限法则给 α²=d，且 α≥1，因而识别 α=√d。算法本身不要求预先知道这个数。

对 m,j≥N，aₘ,aⱼ 都属于 [a_N,b_N]，故 |aₘ−aⱼ|≤2⁻ᴺ。这是一个对**全部尾项**成立的 Cauchy 模数证书，不是看有限配对的最大值。页面取 ε=2⁻ᵉ，给出的充分阈值 N=e+1。若 N=e，则这个非严格上界没有给出“<ε”的证书；这不宣称实际距离必然≥ε，更不否定 Cauchy 性。

### 在 ℚ 中失败的共同原因

对 d=2 或 3，若 aₙ 在 ℚ 内收敛到 q，则由残差界得 q²=d。写 q=p/r 为最简有理数，p²=dr²。素数 d 整除 p，再由代入知 d 整除 r，矛盾。这里的不可能性来自整除证明，不是计算机检查了许多小数位。

这也同时给出：

1. aₙ 单调、有上界，却无有理极限。
2. Iₙ=[aₙ,bₙ]∩ℚ 非空、相对闭、有界、嵌套、长度趋零。若 q 属于所有 Iₙ，因 q≥1，可平方夹逼得 q²=d，矛盾。因此无限交集为空。每个有限交集等于最末区间，仍含无限多个有理数。
3. aₙ 是有理 Cauchy 数列，却不在 ℚ 中收敛。
4. 设 zⱼ=(−1)ʲaⱼ，j≥0。此列有界。在 ℝ 中偶数子列收敛到 α，奇数子列收敛到 −α，所以整列不收敛。若任一子列在 ℚ 中收敛到 q，则其平方仍由同一残差界趋于 d，必须 q²=d，矛盾。这证明其**任何**子列都不能在 ℚ 中收敛，而非只检查了偶数、奇数两条。
5. A={x∈ℚ:0≤x,x²<d} 非空且有上界，但无有理上确界，见下一节的穷尽候选证明。

ℚ 是稠密的。图中的空心点只表示一个实数参照不属于当前数系，不表示一个正宽度区间没有有理数。有限点图不承担刻画全部有理数的任务。

### 正常对照 d=9/4

n≥1 时 aₙ=3/2，bₙ=3/2+2⁻ⁿ。因此 aₙ 在 ℚ 中也有极限，闭区间套在 ℚ 中交于 3/2。A 的上确界 3/2 不属于 A（因为 A 用严格不等式），但属于 ℚ。zⱼ 的两条子列在 ℚ 中收敛到 ±3/2。一个正例不证明五个**普遍**命题成立；图的 ℚ 节点不会因换到这个目标而变绿。

## 4. 上界检查器为什么是解析反例，而不只是数值搜索

候选 q 是精确有理数。

- 若 q<0，0∈A 且 0>q，直接反驳。
- 若 q≥0 且 q²<d，令 h=min{1,(d−q²)/[2(2q+1)]}>0。因为 h≤1，(q+h)²−q²=h(2q+h)≤h(2q+1)≤(d−q²)/2<d−q²。因此 r=q+h∈A 且 r>q，故 q 不是上界。
- 若 q>0 且 q²>d，令 r=(q+d/q)/2。则 0<r<q，且 r²−d=(q²−d)²/(4q²)>0，故 r 是更小的上界。q 不是最小上界。
- 若 q²=d 且 q≥0，则 q 是上界。任何 c<q，若 c<0 可用 0；否则 (c+q)/2∈A 且大于 c，所以 q 确为最小上界。

平方等于 2 或 3 的有理候选不存在，前三种情形穷尽所有 q∈ℚ。d=9/4 则可精确命中 q=3/2。检查器接受有限范围的分数字符串与有限小数，不能把“无法输入无理数”当作无理性证明。

**展示构造与一般证明的等号约定：** 常规展示把 m²=d 归到左端，以保留宽度 2⁻ⁿ；一般 CC→LUB 证明须把“是上界”的中点归到右端。d 非平方时没有区别；d=9/4 时不同。这一点在对应证明中明确提醒，不能把展示的 aₙ=3/2 叫成“不是上界”。

## 5. 可计算范围与误差分层

UI 显示 n=0…32。数学纯函数支持构造到 512 层；Cauchy 配对允许选择晚于 N 的远端下标，精确计算分数差。越过浮点分辨率后，两点的 Number 坐标可能相等，但精确分数差仍可非零。尾部放大先算精确差再换成比例，避免用两个近似大数相减。

区间端点、宽度、残差、上界反证点、尾部距离均由 BigInt 有理算术算出。十进制显示带“≈”，图像明示有限示意。像素宽度可能小于 1；不以此报告交点、极限或完备性。无符号代数、自动证明器、任意无限数列输入或自动判定无限多项算法。

## 6. 理解检查与解析

### 同一条逼近 √2 的有理数列，切换数系后哪句话正确？

正确选项：它在两边都满足 Cauchy 条件，但只在 ℝ 中有极限。

尾部距离不因环境从 ℝ 换成 ℚ 而改变。不同的是极限必须属于所讨论的数系；精确有理运算不会突然生成 √2。

### 每个 [aₙ,bₙ]∩ℚ 都非空。能直接推出它们的无限交集非空吗？

正确选项：不能；∀n∃qₙ 与 ∃q∀n 不是同一个量词顺序。

在 √2 的构造中，任意有限交集都含无限多个有理数，而无限交集在 ℚ 内为空。区间长度趋零且闭、嵌套仍不能替代数系的完备性。

### zⱼ=(−1)ʲaⱼ 有界。在 ℝ 中，BW 究竟保证什么？

正确选项：至少一条按原下标递增选出的子列收敛。

偶数项趋于 √2，奇数项趋于 −√2。BW 只承诺存在一条域内收敛子列。没有 Cauchy 条件，不能把这个终点传给全列。

### 换一个新序列：Hₙ=1+1/2+⋯+1/n。相邻差趋零，是否 Cauchy？

正确选项：不是，因为 H₂ₙ−Hₙ≥1/2。

H₂ₙ−Hₙ=∑ⱼ₌ₙ₊₁²ⁿ 1/j≥n·1/(2n)=1/2。任意晚的尾部仍能找出相距至少 1/2 的两项；m,n 必须允许独立且相隔很远。

### 想改动闭区间套的条件，哪组结论准确？

正确选项：(0,1/n) 交集为空；[0,1] 的恒定套交集非空但不唯一。

0 不属于任何开区间 (0,1/n)，正数最终也被排除。恒定套 [0,1] 的交集仍为 [0,1]。闭性与长度趋零扮演不同角色。

### 把目标改成 3/2，在 ℚ 中也得到上确界和极限。这说明什么？

正确选项：本例成功，但不能证明“每一个”都成功；√2 仍是反例。

一个正例只能说明一个构造成立；一个符合前提而违反结论的反例，已经足以否定普遍命题。图中 ℚ 的五个节点不会因这个正例变为成立。
