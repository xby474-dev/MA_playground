## 新增数学检查

- 八个通项族与独立表达式/已知和核对；所有测试下标为合法正整数。
- 比值普通极限、根值上极限、0/1/>1 边界和无穷零分母。
- 稀疏尖峰无界但商不趋无穷；大整数的2幂检查不依赖浮点 log2。
- 固定参照的双侧界、c=0/∞ 有效单向扩展，以及振荡商不冒充极限扩展。
- 正项、绝对/条件收敛、原级数发散分别判定；交错赋号不能自动激活 Leibniz。
- 不单调抵消用完整奇/偶部分和论证，不仅验证分组和。
- 参数网格上检查所有实线蕴含、所有反推见证以及不可比的双向见证；方法给出的结论不与独立解析分类冲突。
- 改变有限 N 和 probe 不改变解析结论。CSV、白名单路由、图形有限数值与内容完整性检查。

这些检查核对程序；一般命题的论证写在 `SERIES-MATHEMATICS.md` 和本地证明页，数值样本不构成证明。

## 本轮发现并修复

1. Leibniz→收敛的图线原本过于靠近“通项趋零”节点，调整曲线并增加SVG几何回归，避免暗示错误箭头。
2. 有界振荡商虽能直接比较，但不是“极限比较的单向扩展”，已更正状态文字与测试。
3. 稀疏2幂检测改为整数反复除2，避免大数浮点 log2 误判。
4. 含零的交错赋号不等于非零项严格交替，单列提示。
5. 新问答的单选事件误入旧问答全局监听，产生错误；将旧处理器改为只接收其负责的经典实验事件，而不是扩展排除黑名单。修复后六套浏览器全部通过。
6. 证明页区分当前级数用于对照与真正满足前提的正例，不宣称任意当前参数都是正例或反例。

## 环境限制——不能省略

实际执行默认 HTTP 浏览器入口时得到：

```
Page.goto: net::ERR_BLOCKED_BY_ADMINISTRATOR
http://127.0.0.1:4173/MA_playground/
```

完整失败记录在 `delivery/served-browser-policy-block-v1.5.log`。没有更改策略或尝试绕过。浏览器测试改用项目明确支持的 `--offline-harness`，把**实际构建的完整离线 HTML** 注入空白页执行，不使用模拟 UI 或专用测试数学。脚本默认仍是HTTP模块版，供正常开发和CI使用。

真实 Node 服务另行请求了根路径、仓库子路径、模块与静态资源。此结果**不等于浏览器通过 HTTP 加载模块的全链路测试**，也不等于操作系统双击本地文件的策略测试。

没有测试 Safari、Firefox 或完整屏幕阅读器流程；没有运行本轮远端 GitHub Actions，也没有公开部署或 push。实际功能提交与交付校验写在 `delivery/manifest.json`，不能把隔离环境的本地历史说成已发布远端。

## 数学与数值边界

方法版本、尾部条件、参照与量词明确固定；不把所有方法排总序。积分只采用合法的正连续单调插值。归一化比值在log域计算，部分和使用补偿加法；它们仍是浮点显示，不是严格区间算术。Leibniz余项区间来自解析定理，但显示端点不声称向外舍入认证。
