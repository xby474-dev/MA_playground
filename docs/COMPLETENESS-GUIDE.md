# 五种定理，同一个终点：操作指南

## 先问一个问题

“每一步都用有理数算出来，终点一定还是有理数吗？”

进入第四个实验 `#lab=completeness`，或离线入口 `dist/completeness-lab.html`。全部运算、图形、教学内容在浏览器内完成，无后端、无 CDN、无字体下载或 API。

## 连续学习路线

1. **看见等价。** 点击图的五个节点进入同一构造的不同视角；点击任何箭头查看独立证明。右侧可以指定出发、到达节点，沿有向环显示推导路线。绿色箭头不因数系切换而失效；ℚ 中五个普遍断言不成立。
2. **同一构造。** 从 [1,2] 二分开始，不输入平方根近似，只比较有理中点的平方。拖动层数、手动前进/退回、或播放逐次二分。五个视角保留同一目标、层数和参数。上界检查器允许输入 `7/5`、`1.4`、`3/2` 等，输出一个精确的击破点，或确认这个有理候选确为本例上确界。
3. **切换数系。** 在 ℝ/ℚ 间切换，不改计算步骤。观察原来的单调、有界、闭、嵌套、Cauchy 条件是否还在；消失的是要求属于数系自身的终点。换成 3/2 的正例，避免把“不完备”误读成“每个构造都失败”。
4. **闭合证明。** 五条箭头组成独立证明环，每条四步可单独展开，也可一次读完。明确允许使用的起点，以及在哪里使用单调、闭性、阿基米德性、无限下标、三角不等式。可返回原参数实验，不重开无关例子。
5. **自己判断。** 六个迁移判断包含有理数域内收敛、量词顺序、子列、调和和相邻差、开区间套、正常对照。提交后显示解析理由。答案只在当前页面内存保存，不写 URL 或持久存储。

## 五个视角

- **上确界：** 区分集合元素、上界、最小上界。集合用严格不等式，所以上确界可以不属于集合。图里的点只是有限有理样本。
- **单调有界：** 同一组 aₙ,bₙ 成为两条数列。连线只追踪下标，不暗示其间已经定义了连续曲线或证明了无限极限。
- **闭区间套：** 最多显示最后六层；可放大到其中最早一层的坐标范围。有限区间的宽度仍严格为正。目标标记可隐藏。
- **BW：** zⱼ=(−1)ʲaⱼ 在两侧跳动。选偶数或奇数项，保留原始下标，不进行排序。明确区分整列与子列。
- **Cauchy：** N 就是当前二分层数；选择 ε=2⁻ᵉ，以及任意远的两个尾部下标。页面同时给出精确距离和对全部尾项成立的上界。点击“跳到可保证的 N”使用充分阈值 e+1，而不是搜索少量采样点。

## 交互与可访问性

所有节点、箭头、按钮支持 Tab 导航；SVG 节点/边可用 Enter 或空格激活。图形配有标题、相邻文字解释和精确分数读数。手机使用纵向证明环，图旁另有小型二分控件；完整控件继续保留。

没有自动开始的动画。显式播放可以暂停；切屏、换实验、浏览器隐藏时停止。尊重 reduced-motion，采用离散慢步，不用连续飞行动画。完整屏幕阅读器审计不属于已验证范围。

## 分享、离线与数据导出

“分享实验”包含目标、数系、视角、层数、尾部参数、证明步骤等；不包含测验答案。本机离线地址仅适合同一文件/设备，公开分享需要部署后的地址。无剪贴板权限时出现手动复制对话框。

CSV 输出每一层的精确分数、宽度、平方残差与是否命中有理目标，附数系与有限数据声明。CSV 不包含 BigInt 的 JSON 字面量，也不把分数转成浮点近似。
