当前环境禁止浏览器导航到本地 HTTP/文件地址。采用各套件明确提供的 `--offline-harness --browser /usr/bin/chromium`，把**实际构建的完整离线 HTML**送入浏览器执行（Playwright set_content）。没有修改浏览器政策，没有用模拟 DOM 代替应用。

因此：已经验证实际交互和离线构建中的脚本执行；**未验证浏览器 HTTP ES-module 加载全链路**。HTTP 资源由 Node/真实服务器请求独立检查，两类结果不能混称。未完成公开站点、Firefox、Safari 或完整屏幕阅读器验收。
