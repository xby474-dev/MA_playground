# 一个关系实验，不是一份知识点目录

## 开始

离线打开 `dist/relations-lab.html`，或启动站点后选择左栏“02 四个性质，一张图”。所有操作都在本机浏览器内完成，没有后端、登录、追踪或外部公式服务。

第一屏的核心是有向图。绿色实线是定理，点击“为什么成立”；暖色虚线标注 ⇏，点击“反例在哪里”。这些不是尚待确认的定理，而是已经被反例否定的逆推。节点上的 ? 仅表示你尚未判断当前函数。

## 连续路径

**01 建立关系。** 选择函数，先填写 P、C、D、C∂ 的判断，再揭晓四个节点。点击节点检查定义，特别留意“在原点”和“在某邻域”的差别。

**02 正例走通。** 圆碗走 C∂→D，波面走 D→P，椭圆碗走 D→C。底部“继续”保持这条顺序。四个光滑正例可随时切换，sin x cos y 的切平面是 z=x，不是所有例子都用 z=0。

**03 尝试逆推。** 先让光滑圆碗走 D⇏C∂。两端都成立，只说明这个例子没有击破逆推，不能宣布逆推有效。

**04 反例破局。** 换成 x²sin(1/x)，再依次走 xy/(x²+y²)、|x|+|y|、xy/√(x²+y²)。前三个对应本次指定反例；第四个保留旧版关键内容，说明连续与偏导存在合在一起仍不够。

**05 自己判断。** 三个未在主选择器预先展示的函数，各自判断四个性质并选择理由。提交后给出逐项反馈和严格解释。可以带着它们回到同一套曲面、截面、误差与偏导图观察，再回到答题。

不必强制按顺序完成。关系图可以直接进入任意箭头，说明页也保留返回图与展开完整图的入口。

## 同一函数的四种证据

- 曲面：拖动或用方向键转动，Home 重置。显示已证明的切平面、尚未通过检验的候选平面，或明确显示无法由偏导生成 L。
- 截面：切换 x 轴、y 轴、对角线，正负侧都看；实点是原点值，空心点是路径缺口。
- 误差：切换函数值、绝对误差与归一化误差。偏导不存在时，显示的是相对高度，不冒充余项。
- 偏导：看邻近点导数，而非原函数。高频反例用两列精确点显示 −1、+1；比值反例用 ±n 暴露无界。

滑块改变数值与图形，不重建输入，键盘焦点得以保留。显式动画可以暂停，切换页面会停止。减弱动态效果设置不会触发自动播放。

## 教材图里的特殊箭头

关系图底部单独保留“邻域内全部偏导存在且有界 → 连续”。点击后会解释折线路径上的中值定理、局部 Lipschitz 估计，以及为什么它不能再升级为可微。不要把这条带条件的定理与 P⇏C 混为一谈。

## 分享、记录、兼容

分享链接包含函数、箭头、视图、方向、距离、序列下标与是否揭晓节点；不包含学生答案。答题草稿只在当前页面内存中保存，刷新不承诺保留。

CSV 包含 101 个有限尺度以及原始值、线性项、余项、归一化量和解析上界。不存在的导数相关量留空，不写成 0。

旧版双函数比较界面保留在 `#lab=differentiability&mode=classic`，用于旧链接和回归测试；新导航和离线新入口默认只显示统一关系实验，没有增加第四个侧栏模块。

手机使用可读的纵向树与可点击逆推，不是把桌面图缩到无法阅读。证明与数学说明随 HTML 一起离线交付。
