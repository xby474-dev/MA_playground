# 第三个实验怎么使用

入口：网站侧栏“局部累积，边界回声”，或直接打开构建生成的 `field-lab.html`。它和原有两个实验在同一个应用中；无账户、后端、CDN、API Key 或运行时依赖。双击离线 HTML 即可，不必安装 Node。

## 一条连续学习路径

1. **Green**：选一个小方格，读它四条边的环流。比较局部旋度密度、整块积分与四边之和。改变 n，观察单块贡献与总积分的不同。
2. **平面通量桥梁**：保持同一个场和同一个域，改读穿过边界的法向分量。注意现在是散度，而不是旋度。
3. **Gauss**：方格变成体元，公共边变成公共面。改变透视观察层，选中一块。检查六面之和和散度体积分，再观察闭合外壳。
4. **Stokes**：回到环流主线，调节曲面隆起 h。边界固定，曲面法向和实际面积因子变化，但边界环流不变。局部读数会将单位面积密度、参数面积密度区分开。
5. **统一视角**：用同一参数组对照四种读数。再在独立奇点例子中切换圆盘/环域，检查为什么不能忽略内边界。

每一站共用四个步骤：**局部量 → 累积 → 抵消 → 整体**。可以直接点步骤、手动拖动抵消进度或播放动画。系统启用“减少动态效果”时自动跳到结果，仍可手动逐步阅读。

## 参数与观察

- b 改变旋转项；a 改变源汇项；c 改变非均匀程度。输入值均经过约束。
- L 改变实际区域，不是相机缩放。n 只改分块数量，不改场或域。
- “反向定向”同步改正相应积分的符号，局部导数和向量场不会因此改变。
- Stokes 的 h 改曲面形状，三维观察角度只改显示。
- 点击网格或用数字框选块。数字框提供键盘等价操作。手机优先展示图形，参数卡位于图形与读数之后。
- 配对账本中的两个数字分别来自相邻区域自己的积分；并非复制一个数字后硬添负号。

## 已学过公式的使用者

在“参数化与定向”展开额外参数，使用负 a、负 b 或定向反转测试符号。到“定义与证明”查看矩形/长方体的基本定理推导，以及曲面拉回参数平面时的链式法则拆解。

CSV 导出每个小区域的局部积分、独立边界积分、二者差值与参数元数据。它不是采样拟合报告，也不能证明一般积分定理。八道自测包含符号、维数、面积因子、孔洞及证明范围；作答仅保留在当前浏览器会话。

## 分享与离线

“分享实验”将当前站点、学习面板、参数、步骤、观察角度、选择等写入 URL hash；不分享测验答案。文件地址只能在同一台设备使用。公开分享应使用已部署的网站地址；本地构建可直接托管到 GitHub Pages。

离线两个入口：`standalone.html` 保留原来的极限首页；`field-lab.html` 默认打开新实验。二者均包含完整的三个实验，并非简化演示。无需联网下载字体，公式使用原生 MathML。

## 图示的约定

颜色、箭头长度、透明度、体元分离与相机投影都是教学显示，不是物理量的精确尺度。面积/体积上的结果始终取自解析积分。局部密度显示的是中心点值；有限块积分除以面积/体积通常只是平均值。本例的仿射密度具有中心值等于均值的特殊性质，界面会注明。曲面实际面积不得与参数面积混淆。
