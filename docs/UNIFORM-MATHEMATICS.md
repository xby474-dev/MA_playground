# 函数项级数与一致收敛：数学约定、证书与反例

MA Playground v1.6，第七实验。所有分类来自下面的解析论证；SVG、有限数据和浮点读数不决定定理真假。

## 1. 从函数列到函数项级数

给定实值函数项 u_n:E→R，S_N=Σ_{n=1}^N u_n。逐点收敛是在每个固定 x 上，数值部分和有有限极限 S(x)。任何函数列 A_N 都可取 u_1=A_1，u_n=A_n−A_{n−1} (n≥2)，使 S_N=A_N。页面的 x^N、移动尖峰、小波纹均用此约定，不是把 A_N 再求和。几何例子则是 u_n=x^{n−1}，S_N=1+x+…+x^{N−1}。

固定 E 和有限候选极限 S 后：

- 逐点：∀ε>0 ∀x∈E ∃N(x,ε) ∀m≥N，|S_m(x)−S(x)|<ε。
- 一致：∀ε>0 ∃N(ε) ∀x∈E ∀m≥N，|S_m(x)−S(x)|<ε。
- E_N=sup_{x∈E}|S_N(x)−S(x)| 是扩展非负实数；一致收敛等价于 E_N→0。

两者均要求所有后续项，不是恰好当前一项进入 ε 带。某些早期 E_N 可能无限，但一致收敛仍只要求最终趋零；本目录中有限/无限的具体结论逐个证明。若根本不存在整个 E 上的有限 S，则 E_N 显示“未定义”，不随意指定 S=0。上确界不一定取到，+∞ 也不是某一点的误差。

右侧“固定点证书”只对当下冻结的 x 有效。跟随模式的 x_N 随 N 改变；它可以反驳一致收敛，但不能据此反驳逐点收敛。

## 2. 正规收敛与 M 判别

本模块“正规收敛”指 **固定整个 E** 上 Σ||u_n||∞<∞。这等价于存在一列非负数 M_n≥sup_E|u_n| 且 ΣM_n<∞：一边取范数自身，另一边用非负级数比较。

不是“在每个紧子集上正规”的局部概念；也不是“尝试过一个粗糙 M 失败，所以不正规”。反例均对最小上界 ||u_n||∞ 证明不可求和。

M 判别：固定 x，数值级数由比较绝对收敛；其和定义 S(x)。对任意 m≥N，

    |S(x)−S_m(x)| ≤ Σ_{n>m} M_n ≤ Σ_{n>N} M_n。

选择数值尾和小于 ε 的 N，得到一致收敛，同时也得到逐点绝对收敛。逐点绝对并不蕴含一致；一致也不蕴含正规或逐点绝对。图上这些是分支，不是一条可任意倒置的链。

## 3. 六个共用部分和的案例

### 3.1 x^N：端点、开区间和缩小的闭区间

在 [0,1]，S(x)=0 (x<1)，S(1)=1；在 [0,1) 则恒为0；在 [0,r] (r<1) 也恒为0。

- [0,1] 和 [0,1)：E_N=1，不取到。x<1 时误差 x^N<1，但可任意接近1；在 x=1（若包含）误差恰为0。
- [0,r]：E_N=r^N，在 x=r 取到，故一致收敛。
- 解析坏点：给定动画中的 0<ε<1，取 x_N=((1+ε)/2)^{1/N}，误差恒为 (1+ε)/2>ε。证明中也可固定 ε_0=1/4，取 x_N=2^{−1/N}，误差1/2。
- 全域逐点绝对：u_1=x；u_n=−(1−x)x^{n−1}。x<1 时绝对和为2x；x=1 时为1；x=0 时为0。
- 全域不正规：n≥2 时 ||u_n||∞=(1/n)(1−1/n)^{n−1}，极值在 (n−1)/n；与1/(en)等价，范数级数发散。
- 缩域后正规：M_1=r，M_n=r^{n−1} (n≥2) 可求和，其尾界 r^N/(1−r) 通常大于真正误差 r^N。界和误差在页面分列。
- [0,1] 上 S 不连续，但 Riemann 可积且积分0；∫S_N=1/(N+1)→0。非一致不自动意味着积分交换失败。
- [0,1) 上 S 连续但不一致：连续极限不能倒推一致。
- 在内部 x<1，N x^{N−1}→0；在 [0,r] 上导数误差范数 N r^{N−1}→0。包括1的全域没有导数一致证书。图中求导“结论”明确指内部，不能将端点单侧读数偷换进去。

固定 b∈(0,1)，令 N>log(ε)/log(b) 即可令 b^m<ε (m≥N)；实现额外校正浮点阈值。b=0、x=1处零误差分别处理。

### 3.2 几何函数项级数

u_n=x^{n−1}，S_N=(1−x^N)/(1−x) (x≠1)；x=1 时为N。

- [0,r]：S=1/(1−x)，E_N=r^N/(1−r)，在 r 取到；M_n=r^{n−1}，正规。
- [0,1)：逐点绝对收敛，S连续；固定 N 后 x^N/(1−x)→∞ (x→1−)，所以 E_N=∞，不一致。每个固定点的误差仍有限。
- [0,1]：在 x=1 发散，因此没有全域有限和函数；E_N未定义。绝不能把它当作“和函数仍存在，只是误差很大”。
- 在 [0,1) 的最小项上界为1，所以不正规；每个 [0,r] 都正规不表示整个 [0,1) 正规。
- 取 x_N=2^{−1/N}，尾差=(1/2)/(1−x_N)>ε（动画 ε≤.45），提供有限 N 的显式坏点，而不是网格寻峰。
- 缩域的导数尾差在 r 取得：Nr^{N−1}/(1−r)+r^N/(1−r)^2→0。
- 缩域的积分：∫_0^r S_N=Σ_{k=1}^N r^k/k；∫S=−ln(1−r)。开区间不套本图的闭区间 Riemann 定理，不把两个发散的广义积分写成有限交换结论。

### 3.3 一致但不正规的交错线性项

E=[0,1]，u_n(x)=(−1)^{n−1}x/n。记 H_N^alt=Σ_{n=1}^N(−1)^{n−1}/n，则 S_N=x H_N^alt，S=x ln2。

E_N=|H_N^alt−ln2|≤1/(N+1)，最大误差在1。交错尾界覆盖所有后续 m，因而一致。||u_n||∞=1/n 证明不正规；对任何 x>0，绝对值级数=xΣ1/n 发散，故不是逐点绝对收敛。

导数列就是常数 H_N^alt，一致趋于ln2；锚点恒0，因而正确求导定理适用。积分为H_N^alt/2→ln2/2。实际范数采用精确表达式的浮点求值，1/(N+1)是解析上界；两者不混淆。

### 3.4 移动三角尖峰：逐点不能保证积分交换

S_N(x)=2N max(1−|2Nx−1|,0)，E=[0,1]。底边[0,1/N]，峰值2N，峰位置1/(2N)。

固定 x>0，m>1/x 后所有 S_m(x)=0；x=0始终为0。因此 S≡0。E_N=2N，在峰顶取到；积分始终是(1/2)(1/N)(2N)=1，和函数积分为0。对应望远镜项的积分为1,0,0,…，所以 Σ∫u_n=1≠∫Σu_n=0。

每个固定点最终所有项为0，故逐点绝对收敛。n≥2时，在x=1/(2n)，S_n=2n，S_{n−1}=2(n−1)^2/n，所以 |u_n|=4−2/n≥2；不正规。

各项连续且Riemann可积，但折点不可微，因此不满足C¹求导定理。CSV显式包含峰顶和支集端点，折点导数保留undefined。图形对尖峰增加解析特征点，不依赖普通网格碰巧撞到尖峰。

### 3.5 小波纹：函数高度一致不控制导数

S_N=sin(2πNx)/(2πN)，E=[0,1]，S≡0，E_N=1/(2πN)，例如在x=1/(4N)取到。

每个S_N光滑并一致趋零，但S_N′=cos(2πNx)。固定**内部点**x=1/2，导数为(−1)^N，不收敛；S′=0。导数误差范数始终1。积分均为0。

不正规：n≥2取x_n=1/2+1/(4n)，相邻波形反号，

    |u_n(x_n)|=1/(2πn)+cos(π/(2n))/(2π(n−1)) ≥ 1/(2πn)。

也非逐点绝对：x=1/4时偶数部分和为0，奇数部分和为交替的±1/(2πn)；相邻差的绝对值级数包含发散的奇数调和子级数。

### 3.6 常数漂移：不能删掉锚点

S_N=N，u_n=1，导数均为0，确实一致收敛；但S_N(0)=N不收敛，函数列处处发散。这只反驳“只要导数列一致”的弱化说法，不是“导数一致+一点收敛”绿色定理的反例。没有有限S，E_N未定义。

## 4. 三种交换的准确条件和证明

### 连续性

每项连续且S_N在E上一致收敛 ⇒ S连续（E的相对拓扑）。给定ε，先选全域误差<ε/3的N，再由这条固定S_N的连续性选δ。三角不等式三段桥完成证明。逐点时，邻近的x可能迫使N改变，所以不能先固定中间曲线。此条件充分但不必要。

### Riemann逐项积分

E=[a,b]为有限闭区间，每项Riemann可积，S_N一致趋于S。先证明S可积：设η=||S_N−S||∞，对分割P，

    U(S,P)−L(S,P) ≤ U(S_N,P)−L(S_N,P)+2(b−a)η。

先令η小，再利用S_N可积选择P。由此合法使用

    |∫S_N−∫S|≤(b−a)||S_N−S||∞→0。

有限和与积分可交换，最后取极限得到∫Σu_n=Σ∫u_n。本模块未把该版本推广到无界区间或广义积分；也未声称一致收敛是必要条件。

### 逐项求导：控制的是导数列，且需要一点收敛

在有限闭区间[a,b]，各S_N∈C¹（可用邻域延拓或相应端点单侧定义）。若S_N′一致趋于g，且存在x₀使S_N(x₀)→c，则g连续，定义

    S(x)=c+∫_{x₀}^x g(t)dt。

微积分基本定理给

    ||S_N−S||∞≤|S_N(x₀)−c|+(b−a)||S_N′−g||∞→0。

再由g连续，S′=g在内部成立。有限和求导后取极限得到逐项求导。正常几何例在[0,r]满足全部条件；小波纹缺少导数控制；漂移例缺少锚点。部分和原本一致本身并不是求导的充分条件。

## 5. 数值与显示的边界

- 曲线是有限采样；收敛类别、上确界是否取到及尾部证书用解析函数独立计算。
- N∈[1,512]只是动画范围，不是定理范围；证书需要更大N会保留公式和所需N。
- 放大窗口不改变E；缩域控件才改变E、范数和真假状态。
- N增加时误差不普遍要求单调。证书对所有m≥N成立，不能以E_N偶然小于ε代替。
- 图形和数字都是IEEE754浮点；不是严格区间算术。高频正弦和极小量有舍入误差，图中零不宣称解析等于零。
- Infinity与未定义分开；零误差对数图用显示下限并标明，不把显示下限解释为误差正下界。
- CSV导出的是切片样本+解析特征点，并记录域、上确界公式和数据局限。它不是自动收敛判别器。
