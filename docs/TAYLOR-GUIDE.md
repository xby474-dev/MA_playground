# Taylor 实验使用指南

## 一条路线，而不是五张展开公式

从“逐层生长”开始，默认展示水平线 T_0，目标为四阶。点击“从 0 逐层生长”，观察橙线逐项加入；拖动生长进度可以暂停在一项加入40%的时刻。此时明确写为 Q=T_m+λc_(m+1)h^(m+1)，而不是已经完成 T_(m+1)。

阶数滑块选择目标并立即展示完整阶数。层数卡片用于查看前面各层。播放时若当前已到目标，就从0重新播放；否则从已保存的小数进度继续。下一步/上一步按钮跳到相邻完整阶。动画目标至多12阶，达到后自动停止。

## 保留同一个问题的参数

函数、a、n、h、窗口、阈值、参考虚线、证明步骤和生长进度写入 URL hash；在探索、误差、边界、证明之间切换均保留。答案只在当前会话中存储，不写入分享链接。

绿色滑块或图上的 a 手柄移动展开点。橙色 x 手柄及 h 滑块移动观察点。移动 a 保持相对位移 h，因此 x=a+h 跟随变化。拖动期间冻结坐标窗；释放后重新以 a 为中心。手柄可用左右键（Shift 加速）、Home/End 操作。flat 反例的 a 固定为0，不提供未经实现的任意中心导数。

## 建议的探索顺序

1. exp 从 T_0 长到 T_4，核对导数表和新项的系数/贡献。
2. sin 在 a=0 比较1阶与2阶：零项不会“长出”新的曲线。改变 a 后再比较。
3. 保留参数进入“检查误差”：一个图固定阶数改变距离，另一个图固定 x 改变阶数。误差为绝对误差，两个图都是 log10 纵轴。
4. 查看解析充分余项界和整段邻域的保证；不要把显示半径误认为最大精度半径或级数收敛半径。
5. 进入“试探边界”：用 exp 在 −2 的反例推翻“每加一阶都更好”；用几何例子区别域和半径；用对数右端点认识端点检查；用 flat 区分无限光滑与解析。
6. 点击证明路径逐步核对，再独立完成8个判断题。

## 输出与无后端设计

`dist/taylor-lab.html` 是完整离线文件，包含全部五个实验，不引用CDN/字体/API。`dist/index.html` 是模块版静态站，适合GitHub Pages。CSV包含T_0…T_12的完整阶数、系数、在观察点的新项、多项式值、误差方法及上界；不把中间动画列成完整Taylor多项式。

不支持任意函数输入、通用符号微分或自动定理证明。这是经过审核的教学实验，不是数值计算认证工具。

## 可访问性与测试边界

没有自动启动动画。遵循减少动态效果偏好时，显式播放每约950ms跳到下一完整阶；通常模式为约1.2秒/阶的连续项增量。切换页面、重置、离开实验、浏览器隐藏时停止动画。参数范围、按钮、图上手柄均可键盘操作；图旁提供文本结论与表格。尚不宣称完整屏幕阅读器、跨浏览器或WCAG认证。
