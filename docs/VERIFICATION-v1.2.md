## 必须区分的浏览器验证范围

本轮实际尝试普通 HTTP 导航，受到环境浏览器管理策略阻止：

```text
Page.goto: net::ERR_BLOCKED_BY_ADMINISTRATOR
http://127.0.0.1:4173/MA_playground/
```

没有改变或绕过浏览器策略。随后显式使用项目的离线验证模式，在 `about:blank` 中注入**实际构建出的完整 HTML**，由 Chromium 执行真实 DOM、MathML、SVG、Canvas 和事件。不是模拟 UI，也不是只做静态字符串检查。

因此：本轮验证了实际单文件应用的浏览器交互，但**未完成“浏览器 HTTP 导航 → ES modules 加载”的整条链路**，也不声称已经验收操作系统 `file://` 权限或公开部署。模块和资源的 HTTP 状态/MIME 由 Node 真正启动服务器后独立请求验证。`npm run test:ui` 和 CI 默认仍使用正常 HTTP 模式，供允许导航的环境运行。

新测试覆盖作者真值表、整个邻域与原点条件的区别、11 个函数的值/偏导、光滑函数的非零梯度、双侧差商、唯一候选线性映射、原点不连续的对角线路径、连续且偏导存在仍不可微、归一化余项、精确上确界与仅为上界的区别、两列偏导恒为 −1/+1 的解析证据、邻域偏导无界、坐标轴舍入、小量消去稳定性、CSV 中缺失导数留空、分享白名单和有向图。

属性结论由 [RELATIONS-MATHEMATICS.md](RELATIONS-MATHEMATICS.md) 中的推导支持，不由有限网格判定。单个正例不能证明定理，前提不成立不是反例，偏导不存在不会被悄悄替换为 0。振荡图显示的 ±1 是两列点上的解析恒等式；测试另用实际导数公式核对。

原极限和场实验的数学/绘图/内容源模块未改动。原 Node 断言保留；两份旧浏览器脚本只对默认导航变化作兼容适配，显式进入 `mode=classic` 继续原比较界面断言，并未删除旧检查以获得通过。
