# 数学规格与证明

本文是教学内容与实现之间的约定。数值测试只检查实现与已推导公式的一致性；下面的论证不依赖测试通过。

## 1. 多元极限：所有直线仍然不够

定义 $F(0,0)=0$，对非原点定义

$$F(x,y)=\frac{x^2y}{x^4+y^2}.$$

分母在非原点严格正。由 $2|x^2y|\le x^4+y^2$，得到 $|F|\le1/2$。

### 直线

固定任意 $k\in\mathbb R$，取 $(x,y)=(t,kt)$。

对 $k\ne0,t\ne0$，

$$F(t,kt)=\frac{kt}{t^2+k^2}\longrightarrow0\quad(t\to0).$$

$k=0$ 时值恒为 0。竖直线 $x=0$ 需要单独处理：$F(0,t)=0$。所以经过原点的**所有直线**确实都给出极限 0。这一结论来自全参数的计算，不是从滑块的有限斜率中归纳。

### 抛物线

固定 $c\in\mathbb R$，当 $t\ne0$，

$$F(t,ct^2)=\frac{ct^4}{(1+c^2)t^4}=\frac{c}{1+c^2}.$$

$c=0$ 退化为 x 轴，并非反例。$c=1$ 给出 $1/2$；$c=-2$ 给出 $-2/5$。结果与参数从哪一侧趋于零无关。

### 二元极限不存在的两个证明

**序列论证。** $a_n=(1/n,0)$ 与 $b_n=(1/n,1/n^2)$ 均为趋于原点的非原点序列，但 $F(a_n)=0$、$F(b_n)=1/2$。二元极限若存在，必须沿这两列得到同一极限，矛盾。

**直接使用 ε–δ。** 沿 x 轴可知唯一可能的极限是 0。取 $\varepsilon_0=1/4$。对任意 $\delta>0$，选

$$0<t<\min(1,\delta/\sqrt2).$$

则 $0<\sqrt{t^2+t^4}\le\sqrt2t<\delta$，但 $|F(t,t^2)|=1/2>\varepsilon_0$。因此该极限不等于 0，也就不存在。

补定义 $F(0,0)$ 的值不会改变穿孔邻域的极限，所以改成 $1/2$ 也不能使函数连续。

### 量词

二元极限要求：给定 ε，存在一个对**所有足够近的非原点**都有效的 δ。逐条直线各自收敛不提供这个统一控制。特别是抛物线 $y=x^2$ 可写为 $y=k(x)x$，其中 $k(x)=x$ 随位置变化，而不是固定斜率。

## 2. 偏导、连续与可微性

取

$$f(x,y)=x^2+y^2,$$

$$g(x,y)=\begin{cases}xy/\sqrt{x^2+y^2},&(x,y)\ne(0,0),\\0,&(x,y)=(0,0).\end{cases}$$

本节所有性质都针对原点。

### 偏导与候选导数

对 $f$，轴向差商为 $t\to0$；对 $g$，两个轴向差商恒为 0。因此两者的两个偏导都为零。

若 $u$ 在原点可微，其线性导数必须满足

$$L(h_1,h_2)=u_x(0)h_1+u_y(0)h_2.$$

这是由沿两个基向量的差商推出的。因此本例唯一候选是 $L=0$；不能选一个其他平面来挽救 $g$ 的可微性。

### 定义

可微性要求存在一个线性映射 $L$，使

$$\lim_{h\to0,\ h\ne0}\frac{|u(h)-u(0)-L(h)|}{\|h\|}=0.$$

等价地，∀ε > 0，∃δ > 0，对所有 $0<\|h\|<\delta$，余项满足 $|R(h)|<\varepsilon\|h\|$。

### 光滑函数

记 $\rho=\|h\|>0$。$R_f=\rho^2$，从而 $|R_f|/\rho=\rho\to0$，与方向无关。取 δ = ε 即完成证明。$f$ 在原点可微，切平面为 $z=0$。

### 连续但不可微的反例

$2|xy|\le x^2+y^2$ 蕴含 $|g(x,y)|\le\rho/2\to0$，所以 $g$ 在原点连续（可取 δ = 2ε）。

令 $(x,y)=(\rho\cos\theta,\rho\sin\theta)$，其中 $\rho>0$，则

$$|R_g|=\rho|\cos\theta\sin\theta|,\qquad\frac{|R_g|}{\rho}=\frac{|\sin2\theta|}{2}.$$

沿轴该比例为 0，沿 θ = 45° 恒为 $1/2$，所以 $g$ 不可微。此时 $z=0$ 只可称为候选平面，而不是已经存在的切平面。

绝对误差趋于 0 不够；$R=O(\|h\|)$ 也不够；必须满足 $R=o(\|h\|)$。

### 所有方向的解析上确界

定义

$$M_u(\rho)=\sup_{0\le\theta<2\pi}\frac{|R_u(\rho,\theta)|}{\rho}.$$

本例 $M_f(\rho)=\rho$，$M_g(\rho)=1/2$。这两个结论都是精确推导，不是程序扫描若干方向得到的近似最大值。页面把这个量与“当前选定方向的误差”分别显示。

### 双侧方向导数

实验的位移半径 ρ 总为正，只展示沿指定射线的行为。双侧方向导数另定义为 $D_vg(0)=\lim_{t\to0}g(tv)/t$。当 $v=(\cos\theta,\sin\theta)$ 为单位向量时，

$$\frac{g(tv)}t=\operatorname{sign}(t)\cos\theta\sin\theta.$$

除坐标轴方向外两侧不一致。所以本例**不是“所有双侧方向导数存在但不可微”的反例**，项目不作那种声称。

## 3. 可视化与数值契约

- 极限实验的横轴参数是 $|t|=10^{-q}$，$q\in[0,4]$。它不等于一般路径上的欧氏距离；面板另报距离。
- 可微性实验的 $\rho=10^{-q}$ 是位移长度，角度 θ 单独控制方向。
- 接近曲线不含原点；原点补定义与沿路极限不是同一件事。余项比例在 ρ = 0 未定义，数学模块返回 `NaN`，界面不会用 0 替代。
- 数据面板显示舍入值。严格结论来自本文件与页面证明，不来自打印的小数。
- 三维视图是正交投影的有限网格，坐标显示比例可能不同。可微性实验的局部缩放保持水平/竖直显示缩放比例不变，使“相对变平”有意义。极限实验则只放大水平坐标，z 轴比例固定并明确标注；不能把屏幕夹角当导数。
- 非退化抛物线截线在原点处分段，路径极限用空心点表示，原点实际值单独表示；不跨越缺口制造连接。
- 极限反例具有任意窄的脊线。普通有限网格可能漏采；因此精确路径代入与二维曲线是主要实验，三维网格只提供辅助示意。
- 方向扫描中的极径是所选误差量，而不是 ρ。角度是输入方向；图像不是误差曲面的直接三维投影。
- 绘图、CSV 与数值面板使用同一个 `math.js`。曲线采用有限样本；CSV 默认 101 个尺度。
