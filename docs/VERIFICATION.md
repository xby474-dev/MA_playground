## 实际运行的命令

```bash
npm run verify
python tests/browser_test.py --offline-harness --browser /usr/bin/chromium
```

`npm test` 中的工程测试会构建生产版本并启动临时本地 HTTP 服务，逐项请求生产资源。测试结束关闭服务；不需要公网访问。

## 为什么浏览器测试使用离线注入模式

本次环境的浏览器管理策略禁止所有 URL 导航，包括 localhost。测试没有修改或绕过该策略，而是在 `about:blank` 中用 Playwright `set_content` 注入**实际构建生成的完整单文件 HTML**，执行与线上版相同的数学函数、UI 和内容。

因此需要区分：

1. 本次确实在 Chromium 中运行了完整的单文件应用，进行了真实 DOM、Canvas、SVG 与键盘操作。
2. 生产 HTTP 的路径、资源、MIME 等另用 Node 的真实 HTTP 请求测试。
3. **没有在本环境完成“浏览器导航到服务器、加载 ES modules”这一整条链的端到端验证。** 默认 `npm run test:ui` 与 GitHub CI 配置使用该模式，等待在允许导航的环境运行。
4. 远端 Pages 页面没有部署，也没有声称已通过线上冒烟测试。
