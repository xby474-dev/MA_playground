## 浏览器测试范围必须分开

本轮首先尝试常规生产网页导航，但环境的浏览器管理策略返回：

```
Page.goto: net::ERR_BLOCKED_BY_ADMINISTRATOR
http://127.0.0.1:4173/MA_playground/
```

没有修改或绕过策略。随后使用项目提供的显式离线测试模式：在 `about:blank` 中注入实际构建产物，运行完整应用的 DOM、MathML、SVG、Canvas 和交互。两个离线入口均经过浏览器加载检查。

这验证了真实浏览器内的完整应用行为，**但没有完成浏览器访问 HTTP 后加载 ES modules 的全链路端到端测试**，也不是对操作系统 `file://` 权限或公开网站的验证。模块资源另由 Node 实际 HTTP 请求检查。默认的 `npm run test:ui` 及 CI 保留常规网页模式，供允许导航的环境运行。

## 数学与状态检查

新数学测试覆盖：独立有限差分核对旋度/散度；势函数梯度；不同正负系数与区域大小的闭式积分；每一小块的内部/边界恒等式；实际弯曲边的独立高斯求积核对；六面通量；共边界几何索引、反向定向与相消；二维/三维配对计数；网格细化不变性；纯旋转、梯度、零场、汇；固定曲面边界、单位法向和面积因子；中心值与平均值的特殊关系；CSV；异常分享参数；图形有限性；证明条件、自测键与完整站点。

这些数值测试核对代码实现。任意场的一般积分定理来自数学论证，而不是通过测试数量。本例的解析证明见 [FIELD-MATHEMATICS.md](FIELD-MATHEMATICS.md)。
