# Derivative as a Linear Map · 数学口径与完整推导

本实验把局部线性化、Jacobian、复合和投影中值定理放在同一条路线中。网页使用二维输入和二维输出以便操作；定理本身在有限维的一般维数下表述。以下是解析推导，不是从有限绘图数据推测的结论。

## 1. 导数的对象与坐标约定

设开集 U ⊂ Rⁿ，F:U→Rᵐ，p∈U。采用列向量和欧氏范数。F 在 p 可微，是指存在一个线性映射 L:Rⁿ→Rᵐ，使

    F(p+h)−F(p) = Lh + r(h),
    lim_{h→0,h≠0} ||r(h)||/||h|| = 0.

这里 L=DF(p)。它不是求出若干偏导后任意拼起来的规则。其唯一性可直接证明：若 L、M 都满足定义，固定单位向量 v，代入 h=tv，除以 |t|，有

    ||(L−M)v|| ≤ ||r_L(tv)||/|t| + ||r_M(tv)||/|t| → 0.

因此 L=M。只看误差 ||r(h)||→0 不够；只验证有限方向也不够。程序显示当前方向误差，同时给出独立证明的全方向上界。h=0 时误差是零，但误差比为 0/0，标为未定义。矩阵奇异只说明这个线性映射不可逆，不妨碍导数存在。

一维时线性映射都形如 h↦ch，所以导数可用一个数表示；一般维数中需要 m×n 的坐标矩阵。

## 2. 为何恰好是偏导列

已知可微，代入 h=te_j，t 从正负两侧趋零：

    [F(p+te_j)−F(p)]/t = L e_j + r(te_j)/t → L e_j.

逐分量看，L e_j=(∂_jF₁,…,∂_jF_m)ᵀ。这就是标准基下 J_F(p) 的第 j 列。由线性性，Lh=Σh_j L e_j=J_F(p)h。

“偏导存在”本身不是可微性证明。第二个旧实验保留这一反例主题；本实验三个预设均为多项式，已有全方向的可微性证明。

图上 h=ρe_j，而不是单位长度 e_j。因此 J_F(p)h 是第 j 列的 ρ 倍；只有输出差商除以 ρ 后，才与该列比较。自由拖动 h 后，页面回到两列的加权和。

### 换基

保持输出标准基，输入改用正交基 B=[b₁ b₂]，则 h=B h_new，h_new=Bᵀh，新矩阵为 J_F(p)B：

    (J_F(p)B)h_new = J_F(p)h.

旋转输入基控件保持物理 h 不变。数值矩阵和输入坐标可以变，输出向量不变。新基中的列是对应 b_j 的方向导数，不应继续称为原坐标的第 j 个偏导。更一般，若输出基也改为 C，则矩阵是 C⁻¹J_FB；本版界面只演示 C=I。

## 3. 三个全局光滑预设和稳定增量

所有预设定义在整个 R²，没有隐藏的定义域边界。p=(p₁,p₂)，h=(h₁,h₂)，ρ=||h||。

### 弯折与抬升

    F(u,v) = (u²−v, u³+v)
    J_F(p) = [[2p₁, −1], [3p₁², 1]]
    R_F = (h₁², 3p₁h₁²+h₁³).

由 |h₁|≤ρ，

    ||R_F||/ρ ≤ ρ sqrt(1+(3|p₁|+ρ)²) → 0.

界不依赖 h 的方向，也不是采样最大值。

### 交叉弯曲

    F(u,v) = (u+v²/2, v+u²/2)
    J_F(p) = [[1,p₂],[p₁,1]]
    R_F = (h₂²/2,h₁²/2).

由 sqrt(h₁⁴+h₂⁴) ≤ h₁²+h₂²，得 ||R_F||/ρ ≤ ρ/2。

### 仿射对照

    F(u,v) = (u+0.7v+0.35, −0.4u+1.1v−0.2)
    J_F = [[1,0.7],[−0.4,1.1]], R_F=0.

平移在增量里抵消；预测对任意 h 精确成立。

程序用这些恒等式计算 ΔF=J_F(p)h+R_F，而不是在很小的 h 上直接相减两个很接近的函数值。这样减轻灾难性消减，但 JavaScript Number 仍是浮点数；“稳定展开”不等于任意精度或严格区间算术。

## 4. 链式法则是线性映射的复合

F:U⊂Rⁿ→Rᵐ 在 p 可微；G:V⊂Rᵐ→Rᵏ 在 F(p) 可微；F 的一个 p 邻域映入 V。记 A=DF(p)，B=DG(F(p))。

令 k=F(p+h)−F(p)=Ah+r_F(h)。由于 r_F(h)=o(||h||)，存在常数 C 使足够小时 ||k||≤C||h||。于是

    G(F(p+h))−G(F(p))
      = Bk+r_G(k)
      = BAh+B r_F(h)+r_G(k).

第一余项 B r_F(h)=o(||h||)。第二项当 k≠0 时，

    ||r_G(k)||/||h|| = (||r_G(k)||/||k||) (||k||/||h||) → 0.

当 k=0 时 r_G(0)=0，单独按零处理。因此 D(G∘F)(p)=B∘A，矩阵写成 J_G(F(p))J_F(p)。第二矩阵在 F(p) 处取值，不是在 p 处。尺寸是 (k×m)(m×n)=k×n；不能一般性反过来乘。本版都是 2×2，特意能显示“反过来仍能算，却通常算错”的对照。

“B(Ah)=(BA)h”是线性代数的精确恒等式，不是声称整个非线性映射复合没有误差。蓝色光点只是传递进度指示；三幅箭头保留完整预测值，网格显示输入小方块的真实线性像。

### 外层预设及界

弯曲外层：G(r,s)=(r+0.4s²,s+0.35rs)，

    J_G(r,s) = [[1,0.8s],[0.35s,1+0.35r]],
    R_G(k) = (0.4k₂²,0.35k₁k₂).

线性外层：G(r,s)=(r+s,−0.5r+s)，R_G=0。

设 b_F(ρ) 为上节 ||R_F||/ρ 的全方向上界，a=||A||_F，b=||B||_F，其中矩阵 Frobenius 范数是算子范数的上界。因为 |k₁k₂|≤||k||²/2，可取

    C_G = sqrt(0.4²+(0.35/2)²)

用于弯曲外层，线性外层取 0。于是

    ||R_{G∘F}||/ρ
      ≤ b b_F(ρ) + C_G (a+b_F(ρ))² ρ → 0.

这是图中复合误差的虚线。界较宽不是实际误差较大的证据。绘图取样只用于连线，不参与判断可微性。

## 5. 投影后的中值定理

设 F:U⊂Rⁿ→Rᵐ 在开集 U 上可微，p≠y，[p,y]⊂U。对任意 a∈Rᵐ，定义

    γ(λ)=p+λ(y−p), 0≤λ≤1,
    C(λ)=F(γ(λ)),
    φ(λ)=a·[C(λ)−C(0)].

可微蕴含连续，所以 φ 在闭区间连续，在开区间可微。链式法则给出

    φ′(λ)=a·J_F(p+λ(y−p))(y−p).

标量 Lagrange 中值定理产生 ξ∈(0,1)：

    a·[F(y)−F(p)] = φ(1)−φ(0) = φ′(ξ)
                    = a·J_F(z_a)(y−p), z_a=p+ξ(y−p).

不必额外假设 J_F 连续。参数区间长度为 1，因此右式不再乘一个额外的 1；y−p 已包含输入位移长度。

界面允许拖单位方向 a。任何非零 a 都只是相应单位方向的倍数，a=0 的等式平凡成立。p=y 时只是 0=0，不冒称正在验证 p≠y 的教材命题。输出图使用相对坐标 C(λ)−C(0)，因此原点表示 F(p)；切线小线段只显示方向，不表示其长度等于速度大小。

### 为什么候选点不是网格“找出来的”

三个预设沿直线路径都是三次以内的向量多项式：

    C(λ)=C₀+C₁λ+C₂λ²+C₃λ³.

记 b=a·C₂，c=a·C₃。中值方程化为

    3c ξ²+2b ξ−b−c=0.

程序独立展开 C_j，再用稳定二次/一次方程求根并保留 (0,1) 内的根。b=c=0 时整个内部区间都是候选。浮点舍入可能退化，界面说明这是数值读数的问题而不是定理失败。存在性依据上一段证明，不依赖求根软件。

## 6. 量词不能交换：一个精确反证

沿主例的 v=0，取 p=(−1,0)，y=(1,0)，有 F(t,0)=(t²,t³)，总位移 (0,2)。若有共同的向量中值点，必须

    (0,2) = (4t,6t²).

第一式要求 t=0，第二式要求 t=±1/√3，矛盾。所以不存在统一点。可是 a=e₁ 的标量式可在 t=0 成立，a=e₂ 的标量式可在 t=±1/√3 成立。

图上滑块是 ξ，而不是 t；两者满足 t=−1+2ξ。所以对应候选为 ξ=1/2 和 ξ=(1±1/√3)/2。不能把这两个参数混用。

正确结论是“每个方向可以各有自己的中值点”，不是“每个例子都不可能有共同点”。仿射映射每个内部点都满足，二次预设的 ξ=1/2 同时满足所有方向；它们作为正常对照保留。
