最快体验 / Quick start
  双击 dist/taylor-lab.html：进入 Taylor 多项式的逐层生长实验。
  完整应用含全部五个实验，无需网络、Node、CDN、外部字体或 API。

其他完整离线入口
  dist/standalone.html      多元极限
  dist/relations-lab.html  偏导/连续/可微关系图
  dist/field-lab.html       Green–Gauss–Stokes
  dist/completeness-lab.html 实数完备性的等价命题

Taylor 操作
  先从0阶开始，点击“从0逐层生长”。播放到所选目标 n。
  拖动生长进度能停在一项加入一半的时刻；继续播放不丢进度。
  图上绿色 a / 橙色 x 可拖动，也可用滑块或方向键。

开发
  Node 22+；npm run dev / npm run verify / npm run preview
  源码模块入口经 HTTP 打开；双击离线请用 dist/ 内的合并文件。
